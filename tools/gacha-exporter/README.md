本工具专为电脑模拟器玩家（MuMu 12 / MuMu 15 / 雷电 / 夜神等）设计，基于底层网络监听技术，无需对游戏 APK 进行任何逆向破解或改包，纯官方绿色安全。

## ⚡ 极速使用步骤（只需 3 步）

1. **启动模拟器与游戏**：
   在电脑上打开 **MuMu 模拟器 12 / 15**（或雷电/夜神），启动《深渊之歌》并进入游戏。

2. **双击运行工具**：
   双击运行 `深渊之歌抽卡记录导出工具-GUI版.exe`。
   看到状态灯变绿 `● 已连接: 127.0.0.1:16384` 即可。

3. **翻看记录并导出**：
   - 进入游戏主界面【招募】→ 点击左下角【记录查询】；
   - 点击工具界面上的【一键全自动翻页】，工具将自动代点翻完并核验条数；
   - 伙伴翻完后，切换到【魔物贩售】同样翻完；
   - 点击【导出并打开 Wiki 分析页】，在网页上点击「导入记录」即可立即查看出金概率与保底水位！
