# 《深渊之歌》抽卡记录一键导出工具 (Windows GUI 免安装版)

本工具专为电脑模拟器玩家（MuMu 12 / MuMu 15 / 雷电 / 夜神 / 逍遥等）设计，基于底层网络监听引擎与 ADB 自动控制技术，无需对游戏 APK 进行任何逆向破解或改包，纯官方绿色安全。

---

## 🌟 核心特性

- **超轻量单文件**：单文件仅 **60 KB**，基于 Windows 10/11 原生内置的 .NET Framework 运行，无需安装任何额外运行库或 Python/Node.js 环境。
- **免配置智能探测**：
  - 自动扫描运行中的各大模拟器进程，秒级定位配套的 `adb.exe`；
  - 自动探测本地连接端口（`5555`、`16384`、`7555`、`62001` 等）并建立连接；
  - 具备自动提权机制（自动执行 `adb root` 激活底层监听引擎）。
- **极速协议直连（0.4s 免翻页全量）**：
  - 工具从游戏明文请求中秒抓一次会话令牌与逻辑服地址后，内置纯托管 Ed25519 签名与 Protobuf 协议栈直接向服务端并行拉取 `441/442` 全量记录（`pageSize=100`）；
  - 彻底告别模拟点击翻页、零误触单抽风险，且与游戏原连接并行不顶号；同时保留被动抓包兜底。
- **对标抽卡分析页的羊皮纸终端 UI**：
  - 深色原木顶栏 + 羊皮纸渐变档案卡 + 伙伴 / 魔物 / 常规三栏并排指标卡 + 虚线统计印章；
  - 统一手绘矢量图标与羊皮纸暖色调排版，消除 Emoji 方框乱码。
- **一键导入分析**：点击【导出并打开 Wiki 分析页】，自动生成标准 JSON（含四池区分记录及捕获到的玩家昵称/UID）、自动复制到剪贴板并呼起浏览器 Wiki 分析页。

---

## ⚡ 极速使用步骤（只需 3 步）

1. **启动模拟器与游戏**：
   在电脑上打开 **MuMu 模拟器 12 / 15**（或雷电/夜神/逍遥），启动《深渊之歌》并进入游戏。

2. **双击运行工具**：
   双击运行 `深渊之歌抽卡导出工具.exe`。
   看到右上角状态灯就绪后，在游戏内点开一次【记录查询】（只需点开，**不用翻页**）或任意会发请求的界面（如背包/邮箱）。

3. **自动全量同步并导出**：
   - 工具捕获到会话令牌后将在 **0.4 秒内自动拉完伙伴 + 魔物全部记录**；后续也可随时点击【全量抓取】秒级刷新；
   - 点击【导出并打开 Wiki 分析页】，在网页上点击「导入记录」粘贴即可查看完整统计！

## 🛠 开发者重新编译与打包

若修改了 `GachaExporterGui.cs` 源码需要重新生成最新产物：

```cmd
cmd.exe /c "taskkill /f /im 深渊之歌抽卡导出工具.exe 2>nul & C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe /target:winexe /r:System.Numerics.dll /win32icon:tools\gacha-exporter\app.ico /out:tools\gacha-exporter\深渊之歌抽卡导出工具.exe tools\gacha-exporter\GachaExporterGui.cs"
```

打包免安装压缩包：
```powershell
Compress-Archive -Path 'tools\gacha-exporter\*' -DestinationPath 'tools\gacha-exporter.zip' -Force
```
