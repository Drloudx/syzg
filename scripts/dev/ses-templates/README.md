# 腾讯云 SES 邮件模板（运维资产，不参与构建）

这个目录放**上传到腾讯云 SES 控制台的邮件模板正文**。

它不属于 `src/`、也不是运行时资源——**模板内容存在腾讯云那边**，
我们代码里只用 `TemplateID` 引用它。放这里是为了让模板**进版本库、可复核、可回滚**。

## `verify-code.html` —— 验证码邮件

> **当前线上模板**：深木色标题栏 + **实线**边框，呼应站点「深原木顶栏 + 半透明羊皮纸面板」的
> 设计语言。对应 **`TemplateID = 62671`**（2026-10-05 过审）。
> 初版是**浅色、无标题栏、虚线**的设计，对应已被取代的 `62664` —— 换模板时改
> `src/config/auth.js` 的 `TEMPLATE_ID` 一行即可，别忘同步本 README。

上传步骤（控制台，一次性）：

1. SES 控制台 → **发信模板 → 新建**
2. **模板名称**：`验证码`
3. **模板类型**：**HTML 富文本**
4. **邮件摘要**：`深渊大书院账号验证码`
5. **邮件正文**：单击**上传**，选本目录的 `verify-code.html`
6. 提交 → **进入审核，官方说 1 个工作日**
7. 过审后把 **`TemplateID`** 记下来（发送时要传）。本项目已过审：**`TemplateID = 62671`**

发送时的参数（`SendEmail` 接口）：

```json
{
  "FromEmailAddress": "深渊大书院 <noreply@mail.yxzmy.top>",
  "Subject": "【深渊大书院】邮箱验证码",
  "Destination": ["user@example.com"],
  "Template": {
    "TemplateID": 62671,
    "TemplateData": "{\"code\":\"123456\",\"minutes\":10}"
  },
  "TriggerType": 1,
  "Unsubscribe": 0
}
```

> `TemplateData` 是**字符串形式的 JSON**（注意那些转义引号），
> 它的 key 必须与模板里的 `{{变量名}}` **一一对应**。
> 本模板用了 `{{code}}` 与 `{{minutes}}` 两个变量。

## 三条硬约束（改模板时别破坏）

1. **只能用内联 `style`**：官方原文"如果 HTML 不要包含外部文件的 CSS"。
   外链图片也会被多数邮箱默认拦截，且拖累送达率——所以本模板**零图片**。
2. **变量写 `{{变量名}}`**，与 `TemplateData` 的 key 对齐。
3. 🔴 **不能出现微信 / QQ / 二维码 / 群号**：官方「允许发送的邮件类型」明确禁止社交类信息，
   模板审核会因此被打回。

## 为什么用 `Unsubscribe: 0`（不加退订链接）

官方建议"开启退订管理链接"是针对**营销类**邮件的。验证码属于**触发类**（`TriggerType: 1`），
用户不可能"退订"验证码——加了反而让收件人误以为是营销邮件，拉低送达率。
