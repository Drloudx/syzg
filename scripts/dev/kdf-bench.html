怎么让它跑起来

任选一种，让页面落到安全上下文里：

  1. 模拟器里用 http://localhost:5173 —— localhost 被浏览器特批为安全上下文。
  2. 手机 Chrome 加白名单：地址栏进 chrome://flags/#unsafely-treat-insecure-origin-as-secure， 填入本页地址（形如 http://192.168.31.248:5173）， 下拉选 Enabled，点 Relaunch 重启浏览器。
    注意：要用 Chrome，微信内置浏览器不行（它是另一套 WebView）。
  3. USB 端口转发：电脑 Chrome 打开 chrome://inspect → Port forwarding → 手机把 localhost:5173 转到电脑的 5173。

生产环境不受此限制：网页是 https://syzg.yxzmy.top， 安卓 App 的 origin 是 https://localhost，两者都是安全上下文。
