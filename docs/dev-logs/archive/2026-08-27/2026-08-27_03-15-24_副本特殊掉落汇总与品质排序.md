# 副本特殊掉落汇总与品质排序
> 生成时间：2026-08-27T03:15:24+08:00
> 触发来源：用户要求副本掉落按品质降序，并额外汇总箱子、黑商人和 BOSS 三类关键掉落，同时保留原房间内容。

## 修改范围
- `src/views/DungeonsView.vue`

## 变更详情
- 所有奖励池内部统一按品质从高到低排列；同品质再按单次概率和名称稳定排序。
- 黑商人的交互奖励入口由原始配置顺序“铜、银、金”调整为展示顺序“金、银、铜”，原始 JSON 不变。
- 在“房间内容与掉落来源”下方新增默认收起的“特殊掉落”区域，提供“箱子 / 黑商人 / BOSS”三个固定标签。
- 箱子和黑商人读取房间交互奖励，BOSS 读取怪物掉落；相同路线配置在汇总区去重，箱子按金、银、铜排序。
- 原有房间内容与掉落来源完整保留，特殊区域仅作为关键掉落的额外汇总入口。

## 验证与测试
- `npm run verify` 中完整构建、旧脚本检查、41 个副本详情文件及单文件 2MB 限制均通过；总验收仍被既有的 0KB `parsed-hidden.json` 阈值检查阻断。
- Playwright 在 1200×900 桌面和 390×844 手机视口验证：特殊掉落默认收起，三个标签均可切换，布局无溢出。
- 以“遗迹·噩梦”为样本验证：箱子汇总按金箱、银箱排列；黑商人内部按金箱、银箱、铜箱排列；BOSS 汇总包含关底 BOSS 和两种中途 BOSS。
- 验证所有展示奖励池均为品质降序，且原房间列表中的黑商人卡片仍保留并正常展示。
