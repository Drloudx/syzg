# 手机端单指拖动副本地图
> 生成时间：2026-08-27T02:33:55+08:00
> 触发来源：用户要求副本路线地图在手机端可以直接使用单指拖动。

## 修改范围
- `src/views/DungeonsView.vue`

## 变更详情
- 手机单指手势由“滚动副本详情”改为直接平移路线地图，同时支持横向和纵向移动。
- 单指松开后按横纵速度继续短距离惯性滑动，并在到达地图边界时停止对应方向，避免无效动画。
- 双指缩放结束后若仍保留一根手指，会无缝切回单指拖动状态。
- 地图外部区域仍使用页面原生滚动；桌面普通滚轮滚动详情、组合键滚轮缩放和鼠标拖图逻辑保持不变。

## 验证与测试
- `npm run build` 通过，41 个副本详情文件均正常生成，单文件仍低于 2MB。
- `npm run verify` 的完整构建、旧脚本检查与副本文件检查均通过；总验收仍被既有的 0KB `parsed-hidden.json` 阈值检查阻断。
- Playwright 390×844 手机视口实测：单指拖动后地图横向位置由 `0` 变为 `172`，副本详情滚动位置保持 `369` 不变。
- 同一手机视口回归双指手势：地图缩放由 `70%` 变为 `160%`，并同步完成二维平移。

## 遗留问题 / 未完成点
