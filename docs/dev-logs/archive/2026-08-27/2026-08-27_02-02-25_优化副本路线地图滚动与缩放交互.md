# 优化副本路线地图滚动与缩放交互
> 生成时间：2026-08-27T02:02:25+08:00
> 触发来源：鼠标位于路线地图上时，普通滚轮被强制用于缩放，导致副本详情无法继续向下滚动。

## 修改范围
- `src/views/DungeonsView.vue`

## 变更详情
- 普通滚轮不再拦截，继续滚动副本详情；仅 `Ctrl/Command + 滚轮`按鼠标位置缩放地图。
- 地图改为隐藏内部原生滚动区域，鼠标按住拖动仍可平移，避免形成嵌套滚动陷阱。
- 新增位于地图左上角的缩小、当前比例、放大和恢复默认视图控制；地图空白处双击可放大。
- 缩放已到 70% 或 240% 边界时保持当前比例，并继续阻止浏览器缩放整个网页。
- 手机单指纵向手势交给详情页滚动；双指手势同时支持以中心点缩放和二维平移。

## 验证与测试
- 前端完整构建通过；副本索引、41 个详情文件及 2MB 限制检查通过。
- Playwright 桌面实测：地图内普通滚轮使详情滚动位置由 0 变为 280，缩放保持 70%；`Ctrl + 滚轮`使地图变为 80%，详情保持 0；拖拽使地图位置由 `(63, 246)` 变为 `(183, 276)`。
- Playwright 手机实测：地图内单指上滑使详情滚动位置由 275 变为 580；双指使地图由 70% 缩放到 130%，并平移到 `(144, 499)`。
- 940×820 桌面和 390×844 手机截图检查通过，缩放控制条位于地图左上角，未遮挡右侧路线节点。
- `npm run verify` 的构建与本次相关检查均通过，但总命令因现有 `parsed-hidden.json` 生成结果为 0KB、低于 10KB 阈值而退出失败；该隐藏奖励数据链不在本次修改范围。
