# 副本路线正交连线缩放与节点避让
> 生成时间：2026-08-24T19:28:46.985Z
> 触发来源：用户要求副本地图改为直角连线、支持滚轮/双指缩放、分散同位置节点，并移除缺失图标产生的问号。

## 修改范围
- `src/views/DungeonsView.vue`
- `src/utils/dungeonData.js`
- `public/data/parsed/dungeons.json`
- `dist/`
- `docs/dev-logs/README.md`

## 变更详情
- 路线连线改为 SVG 正交折线，按水平/垂直转折连接节点，不再使用斜线直连。
- 地图容器支持鼠标滚轮缩放和移动端双指捏合缩放，缩放范围为 70%～240%，切换副本、布局或关闭详情时重置为 100%。
- 对投影后的近邻节点执行展示层碰撞避让，并将同节点的多个房间图标限制在可换行的图标组内，减少地块互相遮挡。
- 对缺失 `roomIcon` 的候选使用同节点候选图标或房间类型语义图标兜底；移除页面中显示的 `?` 占位符。原始 JSON 配置未清理。
