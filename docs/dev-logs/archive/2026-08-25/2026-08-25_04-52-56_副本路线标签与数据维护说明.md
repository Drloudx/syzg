# 副本路线标签与数据维护说明
> 生成时间：2026-08-25T04:52:56+08:00
> 触发来源：将副本路线标签统一为“路线一～路线三”，并确认后续副本数据维护方式。

## 修改范围
- `src/views/DungeonsView.vue`
- `docs/dev-logs/README.md`

## 变更详情
- 路线页签不再显示源码内部名称，按顺序显示“路线一”“路线二”“路线三”；超过三条时自动显示“路线4”等兜底名称。
- 副本数据继续由 `scripts/parse/dungeons.mjs` 调用 `buildDungeonData` 自动生成 `public/data/parsed/dungeons.json`。
- 后续维护只需更新源 JSON：`instance.json`、`dungeonBattle.json`、`dungeonBattleRoutes.json`、`dungeonBattleRooms.json`、`reward.json`、物品/怪物/采集相关表；执行 `npm run data:build` 或 `npm run build` 即会重新生成。
- 新地图会在满足 instance 有 `chapter` 和 battles、关卡未停用、分类为“副本”且有奖励配置时自动进入列表；有路线配置时自动生成路线图，没有路线配置则只显示关卡与已有详情数据。
