# 复刻副本随机房间路线图
> 生成时间：2026-08-24T18:40:38.391Z
> 触发来源：查看游戏源码和资源，复刻副本随机房间路线并支持点击查看房间信息

## 修改范围
- `src/utils/dungeonData.js`
- `src/views/DungeonsView.vue`
- `scripts/parse/dungeons.mjs`
- `scripts/parse/extractDungeonRoutes.mjs`
- `public/data/dungeonBattleRoutes.json`
- `public/data/parsed/dungeons.json`
- `public/images/instancepanel/MapPanelAtlas/map_r_fb_*.png`
- `docs/SPEC.md`

## 变更详情
- 从解密版 `battle.json` 提取副本随机布局的节点坐标、真实连线、起点、终点和布局权重，生成独立路线数据；页面按同一关卡布局权重计算显示约占比，避免把原始权重误当百分比；原始房间与奖励配置保持不变。
- 副本详情弹窗新增布局切换和横向可浏览的路线图，节点使用游戏 `MapPanelAtlas` 房间图标，随机候选以标记区分。
- 点击路线节点后，在路线图下方展示房间类型、可能遇到的怪物、事件/NPC、宝箱/采集交互以及已配置掉落；候选房间内容按配置合并展示。
- 保留现有房间完整明细列表，作为路线图下的可核对数据。

## 验证与测试

- `npm run build`：通过。

- `http://127.0.0.1:5175/`：开发服务可访问，路线图图标资源返回 200。

## 遗留问题 / 未完成点
- 游戏在进入副本时还会按权重再次选定具体候选房间，网页展示的是该节点的全部可能候选，不模拟一次固定随机结果。
- 路线图使用网页可读的地图底板和游戏节点图标，未直接嵌入游戏运行时的 minimap UI prefab。

## 发布影响提示
