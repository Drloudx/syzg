# 副本路线等轴测网格与固定视口
> 生成时间：2026-08-25T04:05:23+08:00
> 触发来源：将副本路线重构为整数等轴测网格，修复连线不直、地图外框随缩放放大及视口裁切问题。

## 修改范围
- `src/views/DungeonsView.vue`
- `public/data/parsed/dungeons.json`、`dist/`（由构建流程重新生成）

## 变更详情
- 将路线节点的源码坐标量化为整数 `(gridCol, gridRow)`，固定入口为左下、出口为右上。
- 使用固定等轴测投影公式将逻辑网格映射到屏幕像素；节点候选图标继续共享同一网格锚点。
- 路线连线改为网格轴向 Manhattan 折线，SVG 使用 `polyline` 绘制，避免自由 2D 像素直线造成视觉歪斜。
- 地图视口边框和底色移至外层滚动容器，内部路线内容独立缩放；保留滚轮、双指缩放与鼠标拖拽平移，并隐藏滚动条视觉展示。
- 路线边界根据投影后的节点与折线点重新计算，限制无意义空白区域。
