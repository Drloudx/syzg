# 副本剧情栏与特殊矿坑归类修正
> 生成时间：2026-08-25T01:50:00+08:00
> 触发来源：统一剧情折叠栏交互，移除不属于标准副本图鉴的蛇腹矿坑混合配置

## 修改范围
- `src/views/DungeonsView.vue`：每张副本卡固定显示“剧情”栏；显示数量和“展开/收起”状态；无剧情入口时显示 0 个并禁止点击。
- `src/utils/dungeonData.js`：运行期排除 `dungeonD` 蛇腹矿坑，不纳入标准副本卡片。
- `public/data/parsed/dungeons.json`：重新生成副本页面数据。

## 变更详情
- “地窖·大扫除”仍属于旅店地窖的剧情入口，默认折叠，点击后显示并将状态文字切换为“收起”。
- `dungeonD` 同时包含主线矿坑战斗、`consume_plan` 特殊层和日常元素石采集关联配置，不再与标准四关副本混排。
- `fileGather.json` 中的 `sfkk_1_shui` 日常采集配置和原始副本/战斗 JSON 均保留，当前只调整标准副本页展示边界。

## 验证与测试
- `npm run data:build` 通过；标准副本卡片 10 个，蛇腹矿坑不在产物中，剧情入口仍保留 1 个。
- 待执行：`npm run verify`。

## 遗留问题 / 未完成点
- 日常元素石采集尚未单独建设日常活动页面，本轮仅从标准副本图鉴中排除。

## 发布影响提示
