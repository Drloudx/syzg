# 副本剧情入口折叠与随机装备图标修正
> 生成时间：2026-08-25T01:25:00+08:00
> 触发来源：隐藏 0 副本地图，区分停用剧情关卡，默认折叠剧情入口并修复随机装备图标

## 修改范围
- `src/utils/dungeonData.js`、`scripts/parse/dungeons.mjs`：识别配置名中的“停用”和 `sldsd_*` 剧情入口；合并同阶段独立旧版副本；读取 `equip/equipGroup.json`。
- `src/views/DungeonsView.vue`：地图筛选只显示有正式副本的地图；正式关卡与剧情/旧版入口分组，剧情默认收起；移除加载失败的副本图标框。
- `public/data/parsed/dungeons.json`：更新副本分组、剧情入口和随机装备展示数据。

## 变更详情
- 阿娜希塔遗迹、蔓晶采石场等副本现在先显示正式流程，停用的六层入口放在“剧情 / 旧版入口”折叠区；旅店地窖的“大扫除”也按剧情/特殊入口处理。
- 0 个正式关卡的独立旧版副本不再单独渲染；同阶段入口会并入正式副本卡片。
- `mode:'equipGroup'` 按源码 `ItemCellUIGrid` 逻辑匹配 `equipGroups.showItemTypeId`，例如 `show_02wq`、`show_02fj`，并通过 `qualityGroups` 计算展示品质和装备等级。

## 验证与测试
- `npm run data:build` 通过，核对正式副本与剧情入口分组（11 个正式副本卡片，旧版入口已并入对应阶段）。
- 待执行：`npm run verify`。

## 遗留问题 / 未完成点
- 副本卡片仍不绘制游戏地图路线，仅展示关卡/房间数据。
