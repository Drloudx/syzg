# 副本路线多房间图标与详情联动
> 生成时间：2026-08-24T19:04:57.000Z
> 触发来源：用户要求放宽副本路线图、在同一路线点展示多个随机房间图标，并让下方房间内容与掉落来源随点击联动。

## 修改范围
- `src/views/DungeonsView.vue`
- `src/utils/dungeonData.js`
- `public/data/parsed/dungeons.json`
- `docs/dev-logs/README.md`

## 变更详情
- 将副本详情弹窗和路线画布扩大，保留移动端横向滑动，降低节点与连线的拥挤程度。
- 从解密 `battle.json` 的 `randomRooms` 和 `roomIcon` 构建每个路线节点的 `variantOptions`，同一节点的多个可能房间同时展示为独立可点击图标。
- 点击具体房间图标时同步更新路线节点、房间摘要和“房间内容与掉落来源”列表，只展示当前节点及当前候选房间的数据；节点连线关系仍沿用源码 `map.link`。
- 原始 JSON 配置未删除或清理，仅在解析结果和页面展示层完成关联与筛选。
