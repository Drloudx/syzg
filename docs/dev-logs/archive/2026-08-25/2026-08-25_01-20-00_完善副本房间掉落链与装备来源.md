# 完善副本房间掉落链与装备来源
> 生成时间：2026-08-25T01:20:00+08:00
> 触发来源：补齐副本装备掉落、宝箱/采集/事件/怪物来源，修复全部筛选和关卡展示不完整

## 修改范围
- `scripts/parse/dungeons.mjs`、`src/utils/dungeonData.js`：新增正式副本房间与随机候选解析，接通房间交互、怪物自动掉落、采集类型和奖励组。
- `src/views/DungeonsView.vue`：详情页展示房间、怪物、NPC、宝箱/采集和具体装备规则；搜索覆盖房间掉落；修复副本卡片网格裁切。
- `src/components/ui/UiRewardCard.vue`、`src/components/ui/UiTag.vue`：补充奖励规则说明、组内累计概率和弱提示标签样式。
- `public/data/dungeonBattleRooms.json`：从外部解密 `battle.json`/`room.json` 提取正式副本引用的房间数据，保留来源字段。
- `public/data/parsed/dungeons.json`：构建产物，包含房间来源链及 `mode:'equip'` 的具体装备奖励。

## 变更详情
- 明确 `通关 reward`、`showReward`、`firstReward` 与房间 `spObj.caijiTypeId`、怪物 `caijiTypeId` 的不同用途。
- `item_441002` 现在可沿链路展示为：阿娜希塔遗迹 → 遗迹·中枢部 → 房间随机候选 → 金/银宝箱 → `baoxiang223/baoxiang222` → 鸟羽弓；同时展示品质、装备等级、单次概率、奖励组抽取次数及累计概率。
- 房间详情保留每层所有房间和随机候选，按战斗、BOSS、宝箱、采集、恢复/事件等交互分组，不再只显示关卡通关奖励。
- 副本卡片使用自然高度和独立滚动，全部筛选下不隐藏后续关卡；搜索可命中房间怪物和交互奖励。
