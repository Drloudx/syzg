# 2026-08-23 01:59:00 筛选行标签固定宽度与选项垂直对齐

## 1. 需求与背景
- 用户反馈：
  - 在物品图鉴等页面的筛选栏中，第一行是 2 字标签（如「大类：」），第二行是 3 字标签（如「稀有度：」），由于标签字符数不同导致各行的第一个筛选项（如「全部」按钮）在垂直方向上错位、无法左对齐。
  - 要求固定筛选行左侧标签的宽度，使所有行的筛选项在同一条垂直基准线上严格左对齐。

## 2. 排查与技术方案
1. **排查原因**：
   - `UiFilterRow.vue` 中的 `.ui-filter-row__label` 之前使用了 `min-width: 48px`，导致 2 字标签（约 39px 撑满 48px）与 3 字标签（如「稀有度：」约 52px 超过 48px）实际渲染宽度不同，第二行的选项容器被向右推移了约 10px。
2. **解决方案**：
   - 将 `UiFilterRow.vue` 的 `.ui-filter-row__label` 统一设置为固定宽度 `width: 60px; min-width: 60px; flex-shrink: 0; text-align: left;`。
   - 这样 2 字（大类、分类、状态、标签、章节、职业等）与 3 字（稀有度、子分类等）标签均能严丝合缝地容纳在 60px 的标签列内，各行的 `.ui-filter-row__options` 选项容器在水平方向上以完全一致的 X 坐标对齐。
