## 变更详情
- 品质色原为 JS 硬编码旧蓝体系（#666/#2b8a2b/#1a6da1/...）与 theme.css `--q1~--q5` 羊皮纸体系不一致；现统一由 `getQualityColors` 运行时读取 `--qN`/`--qN-bg`，CSS 为唯一来源（含读取失败兜底，值与 theme.css 一致）。
- 任务/事件奖励解析原有 taskParser/eventData/gameMappings 三份近似实现；现收敛为 `gameMappings.parseRewardEntries`（输出结构不变：`{entries, text}`），调用方等价替换。
- 职业/元素/地图名各自只剩一份来源。
