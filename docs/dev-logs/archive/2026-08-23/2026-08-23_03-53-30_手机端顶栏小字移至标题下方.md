# [2026-08-23 03:53:30] 手机端顶栏小字移至标题下方

## 1. 需求与背景
- 用户希望手机端与桌面一致：小字「深渊之歌 · 资源库」显示在页面标题下方，而非同行。

## 2. 排查与技术方案
- 原手机端 `@media (max-width: 768px)` 将 `.header-title-wrap` 设为 `flex-direction: row`（标题与小字并排），为既有移动端设计。
- 方案：改为 `flex-direction: column`，小字换行到标题下方，并微调字距/行高。

## 3. 变更详情
- `[MODIFY]` [src/App.vue](file:///e:/Desktop/html/myrzg/vue-myrzg/src/App.vue): 手机端媒体查询内
  - `.header-title-wrap`: `flex-direction: row; align-items: baseline; gap: 6px` → `column; align-items: flex-start; gap: 0`
  - `.header-title`: 增加 `line-height: 1.15`
  - `.header-brand`: 增加 `line-height: 1.2; margin-top: 1px`

## 4. 验证与测试
