# [2026-08-23 03:55:10] 移动端导航悬浮按钮层级提升与尺寸调整

## 1. 需求与背景
- 用户反馈手机端「打开导航页面的按键」（右下角汉堡悬浮按钮 `.nav-fab-btn`）会被角色/物品等详情弹窗遮挡；
- 且该按钮尺寸与「回到顶部」按钮（44px）几乎一致，视觉上难以区分，用户要求调整大小。

## 2. 排查与技术方案
- 层级排查：详情弹窗 `UiModal` 内嵌模式在 `.app-main`（`position: relative`）内以 `position: absolute; z-index: 2000` 铺满主区域（HeroesView 等传入 `:z-index="2000"`），而 `.nav-fab-btn` 为 `position: fixed; z-index: 990` —— 弹窗层级更高，打开详情后按钮被弹窗面板盖住、无法点击。
- 方案：将导航按钮 `z-index` 提升到 `4000`（高于所有页面弹窗 2000/3000），保证任何详情弹窗打开时按钮始终悬浮可点；同时放大按钮至 56px（含 2px 边框实际 60px），与 44px 的回到顶部按钮明显区分；底部间距由 80px 调整为 88px，避免与回到顶部按钮（bottom 24px）视觉重叠。

## 3. 变更详情
- `[MODIFY]` [src/App.vue](file:///e:/Desktop/html/myrzg/vue-myrzg/src/App.vue): `.nav-fab-btn` 样式调整
  - `width/height`: 48px → 56px
  - `bottom`: `calc(80px + var(--safe-bottom))` → `calc(88px + var(--safe-bottom))`
  - `z-index`: 990 → 4000
  - 内部三条横杠 `width: 19px → 22px`、`height: 2px → 2.5px`，保持比例

## 4. 验证与测试
- `npm run dev` + Playwright（390×844）：
  - 打开角色详情前：FAB 60×60、z-index 4000，汉堡横杠为最上层元素
  - 点击角色卡打开详情（`.ui-modal-overlay` 可见）后：`elementFromPoint` 在 FAB 中心仍命中 FAB 内部 span，按钮浮于弹窗之上、可点击
  - 回到顶部按钮 44×44 / z-index 900，与 FAB 尺寸、位置均不重叠
- 截图确认：角色「奇瓦」详情页右下角导航按钮正常显示

## 5. 后续事项与注意事项
- FAB 层级高于全局公告/关于等 teleport 弹窗（其遮罩 z-index 3000），按钮会浮于遮罩之上；如后续希望系统弹窗盖住 FAB，可改为在弹窗打开时隐藏 FAB（监听 modal 状态）。
- 若用户觉得 56px 偏大/偏小，可再微调。
