# [2026-08-23 04:00:52] 导航按钮尺寸统一、详情页内导航可用与回到顶部补充

## 1. 需求与背景
- 用户反馈手机端（角色图鉴等）：
  1. 导航悬浮按钮（汉堡 `.nav-fab-btn`）尺寸需与「回到顶部」按钮一致（44px）；
  2. 详情页打开时，点导航按钮弹出的导航窗口（抽屉）被详情弹窗挡住；
  3. 详情页内容较长时没有「回到顶部」按钮。

## 2. 排查与技术方案
- **尺寸**：上一轮将 FAB 放大到 56px，用户明确要求恢复为与回到顶部同尺寸（`UiBackToTop` 44px）。
- **导航抽屉被详情遮挡**：详情弹窗 `UiModal` 内嵌层级 2000/3000，而 `NavigationMenu` 的 `.nav-mask`(1500)/`.side-panel`(1501)/`.bottom-sheet`(1501)/`.top-overlay`(99) 均低于弹窗层级 → FAB 可点但抽屉在弹窗之下不可见。方案：将导航弹层整体提升至 3500/3501（仍低于 FAB 4000，保证按钮可继续点击开关）。
- **详情页缺少回到顶部**：部分视图的详情弹窗未内嵌 `UiBackToTop`（事件/任务/物品/怪物详情已有）。排查后为缺省的四处补充：角色、魔物、魔物蛋、成就详情弹窗，滚动容器分别绑定各自的 modal scroll id。
