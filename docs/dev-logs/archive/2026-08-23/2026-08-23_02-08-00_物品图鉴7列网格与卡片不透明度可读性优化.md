# 2026-08-23 02:08:00 物品图鉴7列网格与卡片不透明度可读性优化

## 1. 需求与背景
- 用户反馈：
  1. 将「物品图鉴」桌面端的网格布局固定为**一行 7 列**。
  2. 解决物品卡片因背景过于透明导致底图（地图山脉、河流、树木等噪点线条）穿透干扰、文字与图标看不清的问题。

## 2. 排查与技术方案
1. **排查卡片透底原因**：
   - 全局品质类 `.quality-bg-1` ~ `.quality-bg-5` 的背景色透明度仅为 `0.14`~`0.16`（约 85% 透明度）且带有 `!important`，覆盖了卡片原本的羊皮纸底色。底层地图的黑色山峰与地形线条严重穿透卡片，导致名称文本（如「银币」、「氪金」、「神晶」、「营地经验值」等）与地图线条重叠混淆。
2. **卡片质感与可读性重构（`UiItemCard.vue`）**：
   - 将卡片基础背景提升至 **94%~95% 实色高不透明度羊皮纸**（`rgba(238, 228, 212, 0.94)` / 暗色 `rgba(52, 40, 28, 0.94)`），彻底遮蔽底层地图的杂乱线条。
   - 重新定义 `.ui-item-card.quality-bg-1` ~ `quality-bg-5` 品质底色，采用 95% 高不透明度的柔和微色调（如金橙色采用 `rgba(242, 230, 214, 0.95)` 搭配高识别度描边 `rgba(176, 97, 12, 0.5)`），既有品质感又清爽干净。
   - 优化图标槽位内凹立体感与物品名称文字阴影（`text-shadow: 0 1px 0 rgba(255, 255, 255, 0.6)`），确保每行物品名称 100% 清晰锐利。
3. **桌面端精准 7 列布局（`ItemsView.vue`）**：
   - 为 `ItemsView.vue` 的 `.items-card-grid` 配置 `grid-template-columns: repeat(7, 1fr); gap: 8px;`，在平板与移动端平滑响应式降级（5列/4列/3列）。
