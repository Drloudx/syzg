# [2026-08-23 03:30:00] 移动端主内容区空白根因修复

## 1. 需求与背景
- 用户反馈手机端（390×844 魔物蛋图鉴等）页面只显示地图背景、顶栏与悬浮按钮，主内容区完全空白。

## 2. 排查与技术方案
- Playwright 实测（390×844）发现：`.main-layout-row` 高度仅 16px（上下 padding），`.app-main` 高度 0px，而 `.navigation-wrapper`（移动端导航组件外层容器）占据 727px。
- 根因：`App.vue` 中全局挂载的移动端 `NavigationMenu` 根容器 `.navigation-wrapper { height: 100% }`，即使菜单关闭（内部 v-if 全空），仍作为 `.app-container` 列向 flex 的 flex 子项参与布局，把剩余高度全部占走；`.app-main` 被压缩为 0 且 `overflow: hidden`，所有内容被裁掉。
- 方案：非桌面模式下让该容器不参与弹性布局（其内部 side/bottom/top 面板均为 `position: fixed`，高度归 0 不影响弹层）。

## 3. 变更详情
- `[MODIFY]` [src/components/NavigationMenu.vue](file:///e:/Desktop/html/myrzg/vue-myrzg/src/components/NavigationMenu.vue):
  - 根节点增加 `:class="{ 'is-desktop': isDesktop }"`
  - 新增 `.navigation-wrapper:not(.is-desktop) { height: 0; flex: 0 0 0; overflow: visible; }`

## 4. 验证与测试
- Playwright 390×844：修复前 `.app-main` h=0 → 修复后 h=727，筛选栏 210px、表格 508px，页面完整显示
- 移动端汉堡菜单点击后侧边导航仍正常 fixed 浮层
- 桌面 1440×900：左导航/主内容/右信息面板三栏无回归

## 5. 后续事项与注意事项
- 该根因影响所有图鉴页，修复后手机端各页面内容均恢复。
