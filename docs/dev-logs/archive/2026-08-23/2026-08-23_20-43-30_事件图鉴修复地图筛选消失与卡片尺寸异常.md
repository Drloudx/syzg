# 事件图鉴修复：地图筛选消失与卡片尺寸异常
> 生成时间：2026-08-23T12:43:30Z
> 触发来源：用户反馈「探索区域那里还有筛选，现在怎么没了」+「现在的显示好怪」。

## 修改范围
- `src/utils/eventData.js`：`buildEventData` 返回值新增 `mapNameMap`（c1_map~c5_map → 大地图名）
- `src/views/EventsView.vue`：加载后填充 `mapNameMap`；事件卡片覆盖 `UiItemCard` 默认 `max-width:86px`
- 预解析产物：`events.json` 重新生成（含 mapNameMap）
- `docs/SPEC.md`：9.5 事件图鉴章节同步现状（地图筛选组件、徽标位置、品质色来源、名称样式、奖励解析）

## 变更详情
- **地图筛选消失根因**：数据预解析迁移时移除了旧 onMounted 里填充 `mapNameMap` 的循环（该 ref 只被 `mapOptions` 使用），导致筛选选项只剩「全部」，`<UiSegmentedTabs v-if="mapOptions.length > 1">` 整行隐藏。修复：由 `buildEventData` 一并输出 `mapNameMap`，视图加载后填充（预解析与回退两条路径均生效）。
- **显示异常根因**：`UiItemCard` 组件默认 `max-width:86px`，事件页未覆盖 → 3 列（210px 列）里只有 86px 小图卡，左右大片留白、16:9 图槽被压缩、右下角徽标（42×24）相对过大。修复：`.events-page :deep(.ui-item-card) { max-width:100%; width:100% }`，卡片撑满列宽（桌面 210px / 手机 183px）。

## 验证与测试
- 探针实测：卡片 86×74 → **210×144**；筛选行从 1 行 → **2 行**，地图选项 [全部/秋日荒野/索利德山地/魔爪湖畔/黑森林/霜烬平原]
- Playwright：探索区域 Tab（80 个区域、地图筛选共用、卡片 210px ✅）；手机端 2 列 183px、2 行筛选 ✅
- 截图确认：随机事件 / 探索区域、桌面 / 手机均正常
- `npm run verify`：全部通过（产物、残留、build）

## 遗留问题 / 未完成点
- 探索区域 Tab 除「大地图」筛选外无其它筛选维度（与迁移前一致，SPEC 9.5 亦只定义地图筛选）。
