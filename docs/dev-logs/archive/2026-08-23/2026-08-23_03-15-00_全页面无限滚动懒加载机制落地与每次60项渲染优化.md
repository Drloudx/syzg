# 2026-08-23 03:15:00 全页面无限滚动懒加载机制落地与每次60项渲染优化

## 1. 需求与背景
- 用户需求：为全站所有图鉴及列表页面增加懒加载（无限滚动分批渲染）机制，初始渲染 60 项，向下滚动触底时每次自动追加加载 60 项，避免海量数据一次性挂载导致 DOM 节点过多及首屏卡顿。

## 2. 设计与实现
1. **通用无限滚动 Composable（`src/composables/useLazyList.js`）**：
   - 封装高复用性响应式切片：
     - 初始展示 `pageSize = 60` 项（`displayedItems = computed(() => sourceList.slice(0, displayCount.value))`）；
     - 触底阈值预加载（距离底部 250px 时触发 `loadMore()` 追加 60 项）；
     - 数据源变化自适应（用户在顶部搜索、筛选分类或排序时，自动 watch 并重置回首页 60 项）；
     - 支持指定滚动容器 ID 监听与全局 Window 滚动双重容错。
2. **全量页面接入覆盖**：
   - **物品图鉴**（`src/views/ItemsView.vue`）：海量道具分批 60 项渲染，滚动流畅；
   - **装备图鉴**（`src/views/EquipsView.vue`）：海量装备分批 60 项渲染；
   - **角色图鉴**（`src/views/HeroesView.vue`）：全角色大卡片每批 60 项渲染；
   - **怪物图鉴**（`src/views/MonstersView.vue`）：全部怪物分批 60 项渲染；
   - **魔物图鉴**（`src/views/PetsView.vue`）：魔物大卡片分批 60 项渲染；
   - **魔物蛋图鉴**（`src/views/PetsEggsView.vue`）：数据表格分批 60 项渲染；
   - **料理图鉴**（`src/views/RecipesView.vue`）：菜谱配方分批 60 项渲染；
   - **任务图鉴**（`src/views/TasksView.vue`）：任务大列表分批 60 项渲染；
   - **成就查询**（`src/views/AchievementView.vue`）：全成就列表分批 60 项渲染；
   - **事件图鉴**（`src/views/EventsView.vue`）：随机事件/探索区分批 60 项渲染；
   - **兑换图鉴**（`src/views/ExchangeView.vue`）：兑换列表分批 60 项渲染。
