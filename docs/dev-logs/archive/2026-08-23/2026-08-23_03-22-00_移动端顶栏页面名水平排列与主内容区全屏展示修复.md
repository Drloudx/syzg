# 2026-08-23 03:22:00 移动端顶栏页面名水平排列与主内容区全屏展示修复

## 1. 需求与问题背景
- 用户反馈：
  1. 手机端顶部栏中，页面名称与子标题发生纵向多行挤压换行（如“任... / 深渊之 / 歌 · 资 / 源库”），未向 Logo 右侧水平延展显示；
  2. 手机端中间区域的主视图内容消失不见（只露出底层地图背景）。

## 2. 根因分析
1. **移动端顶栏标题换行**：
   - 桌面端 `.header-title-wrap` 使用了纵向 `flex-direction: column`，且 `.header-brand` 设置了较大字符间距但未设置 `white-space: nowrap`；
   - 移动端未覆盖为横向 baseline 对齐并限制不换行，导致在小屏下被图标挤压成多行垂直堆叠。
2. **移动端主区域内容不可见**：
   - 桌面端主区域 `.main-layout-row` 使用了 3 列 Grid 布局（`grid-template-columns: 250px minmax(0, 1fr) 300px`）；
   - 在移动端小屏断点下，左右侧边栏隐藏后，Grid 单列模式在高度约束及部分场景下由于 `display: grid` 行推挤及 `overflow: hidden` 导致 `.app-main` 无法正确计算 100% 伸缩高度。

## 3. 解决方案与实现
1. **移动端顶栏标题重构（`src/App.vue`）**：
   - 统一定义 `PAGE_TITLES` 全局路由名称映射表，确保各路由实时准确输出完整名称（如“任务图鉴”、“魔物图鉴”等）；
   - 在 `@media (max-width: 768px)` 中：
     - `.header-left` 设为 `flex: 1; min-width: 0; align-items: center; gap: 8px;`；
     - `.header-title-wrap` 设为 `flex-direction: row; align-items: baseline; gap: 6px; white-space: nowrap;`；
     - `.header-title` 与 `.header-brand` 均锁定单行不折行，页面名优雅呈现在 Logo 右侧。
2. **移动端主区域 Flex 弹性铺满（`src/App.vue`）**：
   - 在移动端断点下将 `.main-layout-row` 切换为纯净的 `display: flex; flex-direction: column; flex: 1; height: 100%;`；
   - `.app-main` 设定为 `flex: 1; width: 100%; height: 100%; min-height: 0; min-width: 0;`；
   - 保证任何图鉴及视图页面在移动端均能 100% 完整填充满中间可视区域。
