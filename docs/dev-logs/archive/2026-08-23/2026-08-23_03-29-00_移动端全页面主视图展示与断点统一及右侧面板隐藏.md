# 2026-08-23 03:29:00 移动端全页面主视图展示与断点统一及右侧面板隐藏

## 1. 需求与背景
- 用户反馈：
  1. 手机端（如 `390px * 844px` 魔物蛋图鉴等）仍然未显示内容；
  2. 电脑端右侧的「当前模块/网站版本/备注与说明」信息面板，在手机端确认不需要显示。

## 2. 根因分析与排查
1. **断点冲突**：
   - `src/assets/common.css` 与 `src/App.vue` 原先分别在 `767px` 和 `768px` 定义了断点规则，导致某些移动端模式下 `.desktop-only` 产生样式冲突；
2. **移动端侧栏与右侧信息面板未彻底隐藏**：
   - `.desktop-right-container` 在移动端未被强力隐藏，参与了空间占用；
3. **魔物蛋图鉴模板类名修正**：
   - `PetsEggsView.vue` 模板行类名校准为 `.pet-table-row`。

## 3. 解决方案与实现
1. **统一 1024px 响应式断点（`src/assets/common.css` & `src/App.vue`）**：
   - 当屏幕宽度 `<= 1024px` 时（覆盖所有手机、折叠屏及平板竖屏）：
     - `.desktop-sidebar-container`、`.desktop-right-container`、`.desktop-only` 全部强力隐藏（`display: none !important; visibility: hidden !important; width: 0 !important; height: 0 !important;`）；
     - 电脑端右侧信息面板在移动端彻底不展示；
     - `.main-layout-row` 强制为弹性全屏列布局（`display: flex !important; flex-direction: column !important; width: 100% !important; height: 100% !important;`）；
     - `.app-main` 强制占满剩余视口高度（`flex: 1 !important; width: 100% !important; height: 100% !important;`）；
2. **魔物蛋图鉴样式修复（`src/views/PetsEggsView.vue`）**：
   - 将渲染项类名校准为 `class="pet-table-row"`。
