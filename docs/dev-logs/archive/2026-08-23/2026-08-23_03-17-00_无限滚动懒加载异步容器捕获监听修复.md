# 2026-08-23 03:17:00 无限滚动懒加载异步容器捕获监听修复

## 1. 问题原因定位
- **问题现象**：页面滑动到底部时，明明数据源还有剩余项，但没有继续加载后续 60 项。
- **根因分析**：
  1. DOM 规范中，元素的 `scroll` 事件是**不冒泡**（non-bubbling）的；
  2. 页面中各图鉴的网格容器（`UiCardGrid` 等）是受 `v-if="isDataReady"` 控制的，在接口数据异步返回之前并不存在于 DOM 树中；原先在 `onMounted` 中通过 `document.querySelector` 查找元素时该节点尚未挂载，导致监听器未成功绑定；
  3. 普通 `window.addEventListener('scroll')` 无法捕获非冒泡的子容器滚动。

## 2. 解决方案
- 修改 `src/composables/useLazyList.js`：
  - 在 `window` 上使用 **捕获阶段**（`capture: true`）监听滚动事件：`window.addEventListener('scroll', handleScroll, { capture: true, passive: true })`；
  - 无论子滚动容器何时异步挂载，其发生的滚动事件在事件下发捕获阶段都会被统一捕获并精准获取 `scrollTop`、`clientHeight` 与 `scrollHeight`；
  - 阈值设置为底部 `300px`，触底或接近底部时平滑自动加载后续 60 项。
