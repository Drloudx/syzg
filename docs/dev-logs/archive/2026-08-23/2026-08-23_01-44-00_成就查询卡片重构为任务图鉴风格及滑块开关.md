# 2026-08-23 01:44:00 成就查询卡片重构为任务图鉴风格及滑块开关

## 1. 需求与背景
- 用户需求：
  - 将「成就查询」页面外层的展示组件重构成与「任务图鉴」类似的通栏行列表卡片（`UiListRow`）。
  - 参考用户提供的设计图，布局为：
    - 左侧：大号成就分类六角徽标（生活/冒险/探索/隐藏）+ 成就名称与描述文本。
    - 右侧上方：圆润的胶囊滑块开关（Toggle Switch，未收集为灰色左滑块带 `✕`，已收集为青木色右滑块带 `✓`）。
    - 右侧下方：横向排列的奖励图标与数量（`图标 × 数量`）。
  - 整体配色与交互完美融合当前项目的羊皮纸 Wiki 主题，并自适应暗色模式。

## 2. 排查与技术方案
1. **组件库规范复用**：
   - 弃用原先的 `UiItemCard` 网格卡片，改用与任务图鉴一致的 `UiListRow` 通栏列表组件。
2. **结构布局设计**：
   - 左侧 `.ach-card-main`：放置 44px 高清分类六角徽标（`/images/AchievementPanel/achv_icon_*.png`），右侧为加粗标题与描述。
   - 右侧 `.ach-card-right`：
     - 上部自绘胶囊开关 `.ach-switch-toggle`：宽度 54px，高度 28px，滑块 20px，支持平滑过渡动画，点击独立触发 `@click.stop="toggleCollected(item.id)"`。
     - 下部奖励流 `.ach-card-rewards`：横向并排渲染 `rw.icon` 与 `× rw.count`。
3. **主题与响应式适配**：
   - 采用羊皮纸色系（`--paper-soft`, `--text-main`, `--text-muted`, `--border-soft`, `--accent`）。
   - 收集状态高亮与悬浮动效，支持全局搜索脉冲高亮。
