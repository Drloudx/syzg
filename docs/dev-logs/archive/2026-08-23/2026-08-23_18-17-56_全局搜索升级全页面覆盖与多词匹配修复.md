## 变更详情
- 关键词匹配问题说明：原实现为整串 `keywords.includes(q)`——长描述其实是可搜的（子串），但**带空格的多词查询会失败**；现改为按空格切词 AND：每个词都命中即命中（如「辛普拉 长子」），长描述保留在 keywords 中作为短语搜索依据（如「血口荆棘」仍可命中）。
- 索引覆盖（2037 条 / 13 类）：原 8 类 + task 314 / event 20 / explore 80 / exchange 586 / hidden 57。任务条目复用任务页过滤（跳过 demo/伙伴档案），事件按分组标 稀有/普通，探索按章节大地图，兑换含团队/描述，隐藏宝箱含点位/区域/大地图。
- 跳转：task→`/tasks?task=`；event→`/events?event=`；explore→`/events?tab=explore&explore=`；exchange→`/exchange`；hidden→`/rewards`。
- `npm run search:update`：独立重建 search-index/item-sources/types（从磁盘现有 pvp/hidden 产物读取依赖），全量仍为 `npm run data:build`。
