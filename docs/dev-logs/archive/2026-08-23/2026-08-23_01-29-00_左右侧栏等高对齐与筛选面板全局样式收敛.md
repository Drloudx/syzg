# 2026-08-23 01:29:00 左右侧栏等高对齐与筛选面板全局样式收敛

## 1. 需求与背景
- 用户反馈：
  1. 右侧信息栏区域（Infobox）的高度需要与左侧导航目录完全保持一致（等高 / 一样长）。
  2. 针对上一轮为何微调各个视图文件做出释疑，并将筛选区等基础样式收敛至全局主题规范（`theme.css`），避免各页面维护冗余 scoped 样式。

## 2. 排查与技术方案
1. **左右侧栏等高化（Equal Height）**：
   - 栅格容器 `.main-layout-row` 在垂直方向通过 Grid 自动撑满。
   - 左侧：`.desktop-sidebar-container` 与 `.side-panel.desktop-panel` 设为 `height: 100%`，内部 `.side-body` 设为 `flex: 1; height: 100%; overflow-y: auto;`。
   - 右侧：`.desktop-right-container` 与 `.page-info-panel` 设为 `height: 100%; display: flex; flex-direction: column;`，内部 `.info-body` 设为 `flex: 1; overflow-y: auto;`。
   - 结果：左侧导航栏与右侧信息栏顶部起点相同、底部终点相同，高度完全一致（等长对齐）。
2. **样式全局收敛（DRY 规范化）**：
   - 将 `.filter-panel`、`.filter-sticky-bar`、`[class*="-filter-panel"]` 的基础布局与 margin 规范（`margin: 0 0 12px 0; padding: 12px 14px;` 等）统一收敛至 [src/assets/theme.css](file:///e:/Desktop/html/myrzg/vue-myrzg/src/assets/theme.css)。
   - 后续任何视图只需直接套用对应类名，无需再各自书写 scoped margin。
