# 菜谱查询页双列卡片重构与预览弹窗精简 + 事件角标实底化
> 生成时间：2026-08-23T14:48:47Z
> 触发来源：用户要求菜谱查询页改为参考图的双列卡片布局（电脑端一行 2 个）、详细制作弹窗只保留预览大图；并同步将事件图鉴品质角标改为“不透明实底”（参考实底插画卡）。

## 修改范围
- `src/views/RecipesView.vue`：列表布局重构（UiItemCard/UiListRow → 自定义双列卡片）、预览弹窗精简、样式与导入清理
- `src/views/EventsView.vue`：品质角标实底化 + 卡片图槽不透明背景框

## 变更详情
### 菜谱查询页
- **问题根因**：原实现把分类/食材/Buff/来源/预览按钮全部塞进 `UiItemCard` 的 `#extra` 插槽（方形图片槽右下角角标位），内容在 82px 窄槽中相互重叠、悬浮错位，列表视觉异常。
- **重构**：改为自定义 `.recipe-card` 卡片（图标 + 名称/分类标签 → 食材 chips → Buff 文字 → 来源条 → 右上角预览按钮），`UiCardGrid` 双列网格（桌面 `repeat(2,1fr)`，≤640px 单列）；保留 `card-highlight-pulse` 高亮、`#recipe-card-*` id 锚点、懒加载。
- **预览弹窗**：只保留「制作图预览」一节（大图）；移除「分类 / 制作材料 / 获取途径」三节；清理不再使用的组件导入（UiButton/UiInfoRow/UiListRow/UiRewardCard）。
### 事件图鉴
- `.event-quality-badge` 角标：背景改**实底品质色**（getQualityColors 的 `--qN` 实色）+ 固定米白文字 + 品质色描边（不再半透明 rgba）。
- 事件/探索卡片图槽：`.ui-item-card__slot` 增加不透明羊皮纸底色 + 深色描边框，形成实底插画框观感。
