# 2026-08-23 02:51:00 装备图鉴品质背景框与通用资源路径修复

## 1. 需求与背景
- 用户反馈：装备图鉴中的武器/装备卡片（如「冰火双匕」、「熔火巨剑」等）没有显示出与物品图鉴一样的游戏原生品质背景框。
- 原因排查：
  1. `UiItemCard.vue` 之前硬编码了背景图路径 `/images/ItemBagPanel/item_f_${quality}.png`，未通过全局环境资源解析方法 `getImageUrl()` 封装，导致在不同环境下图片路径解析失败或未命中缓存。
  2. `UiItemCard.vue` 的 `quality` prop 类型只定义了 `Number`，若数据中个别条目以字符串传入则无法正确命中数字映射。
  3. `EquipsView.vue` 此前更新了 `.items-card-grid` 类名，结合本次 `UiItemCard.vue` 的底层资源加载修复，彻底解决装备卡片无品质底框的问题。

## 2. 设计与实现
1. **UiItemCard 引入 getImageUrl**：
   - 动态背景图绑定改为 `:style="{ backgroundImage: `url('${getImageUrl(`/ItemBagPanel/item_f_${getQualityFrame(quality)}.png`)}')` }"`。
   - `quality` prop 声明扩展为 `[Number, String]`，兼容所有数据来源。
2. **装备图鉴与物品图鉴 100% 视觉对齐**：
   - 「冰火双匕」（品质 5）正确加载 `item_f_5.png`（橙金品质框），配合 `#ceb896` 偏暖棕名称底框与 `#b05800` 自然琥珀金字色；
   - 所有品阶、所有部位的装备卡片统一渲染 7 列网格与游戏原版品质背景框。
