# 2026-08-23 03:03:00 魔物与怪物图鉴卡片区域放大及5列网格重构

## 1. 需求与背景
- 用户反馈：魔物图鉴（`PetsView.vue`）和怪物图鉴（`MonstersView.vue`）中的卡片边框所占区域过小（卡片缩在 86px 内导致立绘与边框过小，页面留白过大），需要大幅度调大卡片展示区域。

## 2. 设计与实现
1. **魔物图鉴卡片大幅面重构（`src/views/PetsView.vue`）**：
   - 布局升级为 **5 列网格布局**（`grid-template-columns: repeat(5, 1fr); gap: 12px;`）；
   - 卡片尺寸上限提升至 **`140px`**（`.ui-item-card { max-width: 140px; }`）；
   - 移除 `UiItemCard` 默认的物品小方框背景（`background: transparent !important;`），完整呈现游戏原版魔物专属卡框（`petcard_5.png` 等）与立绘；
   - 名字底框随卡片宽度自适应拓宽，字号提升为 12px。
2. **怪物图鉴卡片大幅面重构（`src/views/MonstersView.vue`）**：
   - 布局同步升级为 **5 列网格布局**（`grid-template-columns: repeat(5, 1fr); gap: 12px;`）；
   - 怪物卡片宽度提升至 **`135px`**；
   - 适配移动端与中屏断点（1100px 为 4 列，768px 为 3 列，480px 为 2 列）。
