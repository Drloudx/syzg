# 2026-08-23 02:05:00 详情页内嵌中间区域与移除全屏变暗遮罩

## 1. 需求与背景
- 用户需求：
  - 打开卡片详情页（物品详情、角色详情、魔物详情、任务详情、成就详情、食谱详情等）时，详情组件所占空间需要与中间主要区域（红框所示的 `app-main` / `page-view-container`）保持完全一致。
  - 打开详情页时，**不需要周围变暗的效果**（左侧导航目录栏、右侧页面信息栏、顶部导航条应保持完全清晰可见、无暗色半透明遮罩覆盖）。

## 2. 排查与技术方案
1. **排查原遮罩与全屏遮挡原因**：
   - `UiModal.vue` 原先默认使用 `<Teleport to="body">` 传送到全局顶层，并带有一个全屏 `position: fixed; inset: 0; background: var(--modal-overlay, rgba(24, 14, 6, 0.55)); backdrop-filter: blur(3px);` 的暗色毛玻璃遮罩。这导致无论在哪个页面打开详情，都会覆盖并变暗左侧导航和右侧信息卡。
2. **中间区域内嵌覆盖方案**：
   - 在 `UiModal.vue` 中改造定位模式：
     - 默认模式：取消传送（不 teleport 到 body），直接作为中间区域容器（`.app-main` 或 `.page-view-container`）的绝对定位子元素（`position: absolute; top: 0; left: 0; right: 0; bottom: 0; width: 100%; height: 100%;`）。
     - 去除遮罩背景：`.ui-modal-overlay` 设为 `background: transparent;`，去除 `backdrop-filter`。
     - 窗体样式：`.ui-modal-window` 设为 `width: 100%; height: 100%; max-width: 100%; max-height: 100%; border-radius: 4px;`，内部标题栏与 `.ui-modal-body` 垂直 flex 布局，滚动区自适应撑满。
   - 保留全局弹窗能力：对系统公告（`NoticeModal`）、关于（`AboutModal`）、菜单模式（`MenuModeModal`）、版本检查（`VersionCheckModal`）显式配置 `teleport-to="body"`，保持独立全局弹窗展示。
