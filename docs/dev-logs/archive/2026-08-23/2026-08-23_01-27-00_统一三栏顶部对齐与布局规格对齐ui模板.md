# 2026-08-23 01:27:00 统一三栏顶部对齐与布局规格对齐ui模板

## 1. 需求与背景
- 用户对照 `ui模板.html` 提出多项布局对齐与尺寸规范要求：
  1. 顶部 Header 区域高度与 `ui模板.html` 一致（60px）。
  2. 左侧导航目录区域宽度与 `ui模板.html` 一致（250px）。
  3. 调整右侧区域的高度与内容展示（仿照 `ui模板.html` 的 infobox 设计）。
  4. 将左侧导航、中间内容、右侧信息栏 3 个区域的顶部位置统一对齐在一条水平线上。
  5. 修复内容区与顶部导航栏过近的问题，将内容区到 Header 的间距调整为与 `ui模板.html` 一致的 30px。

## 2. 排查与技术方案
1. **Header 高度与最大宽度**：
   - 确保 `--header-height` 与 `.header-top-row` 为 60px。
   - Header 容器 `.header-content` 最大宽度调整为 1400px，与三栏内容容器对齐。
2. **三栏网格比例与留白（Padding / Gap）**：
   - `.main-layout-row` 严格参照 `ui模板.html` 的 `.wiki-wrapper`：`grid-template-columns: 250px minmax(0, 1fr) 300px; gap: 20px; padding: 30px 20px 20px 20px;`。
   - 顶部间距由原先零散的 0~20px 统一为 `30px`，实现与 `ui模板.html` 的精确对齐。
3. **消除各列顶部不一致的 Margin 偏移**：
   - 左侧：`NavigationMenu.vue` `.side-panel.desktop-panel` 宽度设为 100%（适配 250px 容器），清空 `margin`（原 `margin: 20px 16px 20px 0` 会导致下沉 20px）。
   - 中间：全量修正 12 个视图（`ItemsView`, `EquipsView`, `HeroesView`, `PetsView`, `RecipesView`, `MonstersView`, `AchievementView`, `TasksView`, `EventsView`, `ExchangeView` 等）的顶部筛选面板 margin，统一为 `margin: 0 0 12px 0`，确保顶部 Y 轴与左右栏严密对齐。
   - 右侧：`App.vue` `.page-info-panel` 清除 `margin: 20px ...`，设为 `margin: 0`；同时引入 infobox 顶栏封面与结构化属性行，提升视觉质感。
4. **卡片网格间距微调**：
   - `UiCardGrid.vue` 内部内边距设为 `2px 0 calc(14px + safe-bottom)`，让卡片网格与上方筛选面板两侧对齐。
