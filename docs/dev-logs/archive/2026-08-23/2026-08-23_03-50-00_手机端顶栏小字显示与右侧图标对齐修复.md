# [2026-08-23 03:50:00] 手机端顶栏小字显示与右侧图标对齐修复

## 1. 需求与背景
- 用户反馈：电脑端顶栏标题下方的小字「深渊之歌 · 资源库」在手机端不显示；右上角图标（月亮/设置）右边缘未与下方搜索框对齐。

## 2. 排查与技术方案
- Playwright 多宽度实测（360–1440）：
  - ≤768px 时 `.header-brand` 宽度为 0 `.header-left` 宽度为 0，`.header-right` 占满整行
- 根因：`App.vue` 中 `.header-right { width: 100% }` 基础规则写在 `@media (max-width: 768px)` **之后**，相同优先级下覆盖了媒体查询里的 `width: auto`；flex 布局下右侧占满整行 → 左侧被压缩为 0，小字收缩至 0 不可见，右侧图标也与搜索框右缘错位（实测差 10px）。
- 方案：去掉多余的 `width: 100%`（桌面为 grid 三列布局，grid item 默认 stretch，无需该属性）。

## 3. 变更详情
- `[MODIFY]` [src/App.vue](file:///e:/Desktop/html/myrzg/vue-myrzg/src/App.vue): `.header-right { width: 100% }` → `width: auto`

## 4. 验证与测试
- Playwright 实测：
  - 360/390/480/768：小字宽度 75–92px 可见；图标右边缘与搜索框右边缘完全一致（348/378/468/756）
  - 桌面 800/1440：图标右边缘与内容右缘对齐，布局不变
