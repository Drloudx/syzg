## 2. 项目架构与规范调研总结
- **项目名称**：深歌小助手（深渊之歌 Wiki 工具 / `vue-myrzg`）。
- **技术栈**：
  - 前端核心：Vue 3（`<script setup>`）+ Vite + Pinia（`pinia-plugin-persistedstate`）+ Vue Router（Hash 模式）。
  - 原生支持：Capacitor（Android 原生壳封装）。
  - 样式规范：`src/assets/theme.css`（羊皮纸 Wiki 主题，纯 CSS 变量体系，支持亮/暗色双主题，无额外 CSS 框架）。
  - UI 组件层：`src/components/ui/`，所有视图界面统一强制引用通用 UI 组件库（`UiCardGrid`, `UiItemCard`, `UiModal`, `UiFilterRow`, `UiSection` 等）。
- **数据流与解析**：
  - 数据源位于 `public/data/`。
  - 构建脚本 `scripts/clean-data.js` 生成预处理派生索引（`public/data/parsed/`）。
  - 业务解析由 `src/utils/*Parser.js` 统一处理，解耦视图与数据结构。
