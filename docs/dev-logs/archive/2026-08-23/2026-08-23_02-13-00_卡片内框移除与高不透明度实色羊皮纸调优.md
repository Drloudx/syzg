# 2026-08-23 02:13:00 卡片内框移除与高不透明度实色羊皮纸调优

## 1. 需求与背景
- 用户反馈：
  1. 卡片底色依然有一点透，导致底图仍有些微干扰，要求进一步降低透明度（提高实色不透明度）。
  2. 图标周围存在一个多余的内方框（内嵌槽位），影响美观，要求彻底删除这个内方框。

## 2. 排查与优化方案
1. **删除图标槽位内框**：
   - 将 `.ui-item-card__slot` 中的内凹阴影（`box-shadow`）、背景色（`background`）和内边框（`border`）彻底移除，设为 `background: transparent; border: none; box-shadow: none;`。
   - 物品图标无边框悬浮在卡片上方，视觉极简清爽。
2. **高不透明度实色羊皮纸底色**：
   - 将卡片基础背景与品质渐变底色提升至 **96%~97% 实色不透明度**（`rgba(225, 210, 185, 0.96)` ~ `rgba(224, 210, 186, 0.97)`，暗色模式为 `rgba(46, 34, 22, 0.96)`）。
   - 彻底阻断底层地图任何线条的透底干扰，使卡片保持温润暖棕实色羊皮纸外观。
