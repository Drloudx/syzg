# 移动端页签横滑提示与角色标签配色优化
> 生成时间：2026-08-23T16:22:03Z
> 触发来源：优化移动端互动页签横向滑动体验，并处理角色详情中过深的标签颜色

## 修改范围
- `src/components/ui/UiTabs.vue`
- `src/views/HeroesView.vue`
- `docs/UI_COMPONENT_LIBRARY.md`

## 变更详情
- `UiTabs` 在内容超出可视宽度时显示右侧轻量滚动提示，仅页签栏横向滚动，不引起详情主体横向溢出。
- 切换页签后自动将 active 页签滚动到可见区域；滚动到末端后隐藏提示。
- 角色职业、核心被动和星阶标签由深木色改为浅羊皮标签；星阶等级徽章改为浅色底加描边，降低移动端视觉压迫感。

## 验证与测试
- Playwright：移动端互动页签初始显示滚动提示，点击“自言自语”后自动滚动到末端并隐藏提示。
- Playwright：12 条路由移动端加载审计通过，均无控制台/页面运行时错误。
- `npm run verify` 通过：预解析产物、旧脚本残留检查、生产构建和 dist 产物检查全部通过。
