# 兑换卡片视觉层级与响应式网格优化
> 生成时间：2026-08-24T02:03:03+08:00
> 触发来源：用户反馈当前兑换页多列展示不够美观，要求按 UI 规范调整，并追问前几次变更为何没有留下规范日志。

## 变更详情
- 清理 `UiExchangeTrade` 中旧横向布局与新网格布局重复的样式，统一为稳定的「标题 → 获得 → 消耗 → 限购页脚」卡片结构。
- 卡片使用主题变量、固定最小高度和 hover/focus 状态；礼包图片保留独立顶部图片区，图片失败时仍可回退为普通卡片。
- 物品名称、数量、标签和限购正文统一不低于 13px；物品按钮继续通过 `item-click` 打开详情，图片路径继续由 `getImageUrl()` 处理。
- 普通兑换与 PVP 兑换桌面网格最小宽度调整为 180px、间距 12px；手机端固定两列、间距 8px，避免过窄卡片导致标题和数量挤压。
- 将上述卡片结构、断点和可读性要求写入总规范与 UI 组件库，补足此前变更未留痕的问题。
