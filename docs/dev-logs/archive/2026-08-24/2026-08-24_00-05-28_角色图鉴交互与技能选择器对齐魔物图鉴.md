# 角色图鉴交互与技能选择器对齐魔物图鉴
> 生成时间：2026-08-23T16:05:28Z
> 触发来源：调整角色图鉴样式和点击交互，使其与魔物图鉴靠齐，并排查页面与 UI 组件问题

- `src/components/ui/UiModal.vue`
- `src/views/HeroesView.vue`

## 变更详情
- 修复 `UiModal` 遮罩点击处理引用未定义变量 `closeOnOverlay` 导致的运行时错误，改为读取已声明的 props。
- 角色图鉴技能与星阶选择器统一为魔物图鉴的横向卡片布局、四列桌面/两列移动端、自适应文本和 active/hover 视觉状态。
- 统一选择卡片图标尺寸、间距、圆角和背景色，普攻无图标时保持文字区域尺寸稳定。
- 为星阶等级详情补充窄屏文本收缩与换行约束。
