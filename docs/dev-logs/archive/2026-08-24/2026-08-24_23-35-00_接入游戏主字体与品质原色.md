# 接入游戏主字体与品质原色
> 生成时间：2026-08-24T23:35:00+08:00
> 触发来源：用户要求检查 4.24 包字体与源码品质色，并将网页 theme.css 调整为游戏原本样式

## 修改范围
- `public/fonts/MYR2SansRegular.ttf`
- `public/fonts/MYR2SansBold.ttf`
- `src/assets/theme.css`
- `src/utils/gameMappings.js`
- `docs/SPEC.md`
- `dist/`（重新构建产物）

## 变更详情
- 从 `4.24包/Font` 引入游戏主字体 `MYR2SansRegular.ttf` / `MYR2SansBold.ttf`；源码中的 TextMeshPro 字体资产为 `MYR2SansRegular SDF` 与 `MYR2SansBold SDF`，网页正文与标题统一改用对应源字体。
- 保留 HarmonyOS 作为字体缺失时的回退，不再依赖 Google Fonts 网络导入。
- 根据源码 `Const.cs` 的 `QualityColorString` 与 `ExtentionMethod.GetQulityColorString`，统一 Q1~Q5 原色：`#cfba96`、`#a7c037`、`#3fa2ff`、`#ee62f1`、`#ffb64d`。
- 品质文字、徽章、背景、JS 兜底颜色全部改为同一套变量/原色，移除旧网页自定义的暗化颜色。

## 验证与测试
- `npm run verify`：通过，产物检查、旧脚本残留检查与完整 Vite 构建均成功。
- 字体资源检查：通过，`dist/fonts/MYR2SansRegular.ttf` 与 `dist/fonts/MYR2SansBold.ttf` 均已生成。

## 遗留问题 / 未完成点
- 游戏源码还包含 `SongTi`、`DaBiaoSong`、`HeiTi`、`CuHeiTi` 等旧 NGUI/专用字体；本次先采用源码中明确的 MYR2Sans 主字体，不替换这些专用字体资源。

## 发布影响提示
需要重新发布前端构建产物；字体文件会增加前端包体积约 19MB。
