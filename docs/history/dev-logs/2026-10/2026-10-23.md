# 2026-10-23 开发汇总

## 修复

### QQ / 微信内置浏览器「物品数据加载失败」

**现象**：从 QQ、微信打开站点，图鉴页显示「数据装配未完成 — 物品数据加载失败，请重试」；
普通浏览器（桌面、手机 Chrome/Safari）正常。

**根因（两层）**：

1. **EdgeOne 未开强制 HTTPS**：`http://syzgwiki.top/` 返回 200 而不跳转
   （旧域 `syzg.yxzmy.top` 是 301）。QQ / 微信从 http 链接进入时，页面运行在
   **非安全上下文**，此时 `crypto.subtle` 为 `undefined`。
2. **`resourceClient.sha256()` 强依赖 `crypto.subtle`**：缺失即抛
   `Resource verification requires HTTPS`，`fetchResource` 整个失败 →
   页面渲染成「数据加载失败」。

注意：这不是「老浏览器」问题。**现代 Chrome 在 http 页面里同样没有 `crypto.subtle`**。

**处理**：

| 层 | 改动 |
| --- | --- |
| EdgeOne | `ForceRedirect` → `Switch=on`，`RedirectStatusCode=301` |
| 代码 | `src/utils/resourceClient.js` 新增 `hasSubtleCrypto()`；缺 subtle 时**降级跳过哈希校验**，而非让整页失败 |

**取舍**：哈希校验防的是「CDN 返回错版本 / 被篡改」；缺 subtle 是「页面在 http 下打开」。
后者若直接抛错，用户看到整页失败——比少一层校验更糟。HTTPS 访问仍走完整校验。

**验证**：

- `http://syzgwiki.top/` → `301` → `https://syzgwiki.top/`
- 线上 `blacklist-DNRnuZIb.js` 含守卫：`if(n&&a()&&await c(i)!==n)throw ...`
- `items.json` → `HTTP 200`，2428107 bytes
- `npm run test:unit` 400/0；`npm run verify` 通过
