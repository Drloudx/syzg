# 2026-10-18 开发汇总

## UI 与交互

### 招募页标题位兼作「返回首页」

- `GachaPoolPanel.vue` 的标题位由纯 `<img>` 改为 `<button class="pool-title-btn">`，点击发出 `home` 事件；`GachaView` 接住后跳首页。
- 🔴 **不复用 `handleBack()`**：那个函数走 `router.back()`，招募页常从分享链接、书签或 Android 返回栈直接进入，此时「上一页」可能是站外或空栈。标题图作为明确的「首页」入口，语义必须确定。
- 🔴 **根路由 `/` 是 `redirect: '/items'`**，所以「已在首页」的实际路径是 `/items` 而非 `/`。`handleHome` 从 `router.getRoutes()` 读根路由的 `redirect` 做判据，不写死 `/items`，日后改首页落点会自动跟随。
- 位置仍是 `gachaPos(-500, 315)`，尺寸由内部 512×152 图决定；`.pool-title-btn` 声明 `padding: 0 / border: 0 / background: none`，盒模型与纯图片时完全一致（实测按钮与图片同为 `534×159`，深色切换前后坐标不变）。
- 交互沿用既有规范：`g-hit`（按下亮度反馈）+ `g-focusable`（键盘聚焦金框）+ 原生 `<button>`，可 Tab 聚焦、回车触发。
- 魔物蛋页签同样生效，横幅自动切 `gacha_title_egg.webp`、`alt` 切「魔物蛋贩售」，`title` 恒为「返回首页」。
