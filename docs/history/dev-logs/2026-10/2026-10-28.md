# 2026-10-28 开发汇总

## UI 与交互

### 新增「配队模拟」页（`/team-sim`）

选 4 名角色，按魔物的**队伍被动**推荐出战组合。三块内容：

| 区块 | 内容 |
| --- | --- |
| 出战队伍 | 4 个槽位，显示头像 / 名称 / 职业·属性 + **3 颗点亮标记** |
| 魔物搭配 | 「智能推荐」（自动求最优 3 只）与「自组查看」（列全部）两种模式 |
| 选择角色 | 34 名角色，按职业 / 属性 / 关键词筛选 |

- 入口：`NavigationMenu.vue`、`NavigationMenuLite.vue` 加「配队模拟」；`App.vue` 补标题映射。
- 点亮标记用**游戏原素材** `PetPanel_Atlas/team_buff(_on).webp`（32×28，深色剪影 / 橙色发光）。

### 智能推荐

穷举 `C(32,3) = 4960` 种组合求最优 —— 规模小，拿到的是真正的最优解，不用贪心近似。

排序优先级：受保护角色吃满 > 吃满人数 > 偏好加成命中 > 总点数。

两个筛选（都可多选）：

- **优先点亮**：勾角色 → 优先保证该角色吃满
- **优先词条**：勾加成类型 → 优先保证它出现

### 🔴 「排除通用被动」默认开启

通用 = 队伍被动**不带任何属性/职业限定**（如「队伍伙伴 暴击率 增加 5%」），实测 7 个。

不排除时这 7 个会把 3 个出战位全占满，显示「12/12 满分」却等于没做针对性搭配。
开启后同一队伍的最优解从 `角布林+臭臭蕈+游离灯火` 变为 `掘地芙洛波+格莉姆+蜂刺骑兵`（地属性三件套，3 个地属性角色吃满）。

### 队伍被动的解析难点

原文写法极不统一，用**词表匹配**而非正则推导：

| 原文 | 说明 |
| --- | --- |
| `队伍中 {火属性} 伙伴物理攻击增加 {6%}` | 标准式 |
| `队伍中伙伴魔法防御增加 {4%}` | 无空格、无限定 |
| `队伍中法师辅助魔法防御 {6%}` | 无「增加」二字，且有「法师/辅助」口语别名 |
| `队伍中每有一个【秘术】伙伴，可获得 {5%} 魔法攻击力 提升` | 用【】而非 {} |

`STAT_WORDS` 按长度降序匹配，保证「物理攻击力」优先于「物理攻击」；`JOB_ALIAS` 处理法师→秘术、辅助→支援。

### 🔴 只取索引 3，不取特性

一个魔物 4 个技能里，`trait`（特性）也常带「队伍中…」字样 —— 实测 3 个：
草原黏团 / 魔水粘团 / 熔火喷炎者。

但**特性是角色携带生效，不是编队出战魔物给的**。混进来会算错受益人数。
故 `toPetRecord` 严格只取 `skills[3]`，不做兜底查找（兜底会误抓特性）。

### 图标路径规则

数据里只存**文件名**，不含目录，直接传给 `getImageUrl` 会 404：

```
hero.icon  = "at019_0"       → /images/HeadIconAtals/at019_0.webp
pet.monImg = "colect_mon_007" → /images/PicHandBookPanel_Atlas/colect_mon_007.webp
```

## Bug 修复

### ① 角色/魔物头像全部 404

**现象**：选人区、推荐区的图全是空白。
**根因**：见上「图标路径规则」，直接把裸文件名传给了 `getImageUrl`。
**修复**：视图层加 `heroPortrait()` / `petIcon()` 拼完整路径。

### ② 页面内容滚出容器（跑出筛选框上方）

**现象**：正文滚到吸顶筛选框上面，且截图里侧栏被盖。
**根因**：自建了 `<div class="sim-page">` 当滚动容器，漏了 `data-main-scroll`。
按 [UI_COMPONENT_LIBRARY](../context/UI_COMPONENT_LIBRARY.md) §3 第 9 条「桌面端吸顶裁切三件套」，自建容器必须自己加该标记；`UiCardGrid` / `UiVirtualGrid` 自带。**失败是静默的**，不报错。
**修复**：改用 `UiCardGrid` 当外壳（`content-style` 设单列），不再自建。

### ③ 点亮图标被撑成 64px，盖住角色卡

**现象**：3 颗标记变成 3 个巨型图标。
**根因**：`.sim-slot img { width: 64px }` 同时命中了标记图（标签选择器穿透到后代）。
**修复**：改 `.sim-slot > img` 限定直接子级，移动端断点同步修。

### ④ 角色名下平铺一堆数字（设计失误）

初版把「该角色能吃到几个魔物被动」算出来后，把**每个被动的加成数值**逐个平铺，13 个数字挤在一起，无任何可读性。
**修复**：换成 `team_buff` 三颗点亮标记，与原作一致；悬停显示具体魔物清单。
