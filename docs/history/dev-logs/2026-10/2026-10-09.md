## 重构与维护

- **`src/assets/theme.css` 清理滚动条死代码（观感零变化）**：
  - **问题**：§8 同时写了 `* { scrollbar-color }` 与一组 `::-webkit-scrollbar-*` 伪元素。Chromium 只要 `scrollbar-color` 非 `auto` 就**整体忽略伪元素** → 该组规则**从未生效**，文件写着「8px、无三角」，实际全站一直是系统默认（实测 **15px、带三角**）。§8b 触屏块同理（`scrollbar-width: none` 压掉了 `::-webkit-scrollbar { display: none }`，但 `scrollbar-width` 自己就能隐藏，行为不受影响）。
  - **处置**：删除死代码，保留标准属性；文件与真实表现一致。§8 补写「为什么两种机制不能同时用」及两条正确改法（全站改 / 单容器特例），避免复发。
  - **观感**：全站**不变**（15px、带三角）—— 这正是"删的是死代码"的证据。
- **新增 `src/utils/emoticonRecent.js`**：「最近使用」的纯逻辑（`pushRecent` / `resolveRecent` / 读写 + 脏数据兜底）。单独成文件的原因：`config/emoticons.js` 被服务端 `functions/api/[[path]].js` import，不能在那里碰 `localStorage`。
