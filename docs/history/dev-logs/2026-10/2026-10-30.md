## 修复

### 首页整页长截图只能截一屏（`is-boot-loading` 永不移除）

`App.vue` 的首屏就绪判定只认 `.page-view-container`（要求「页面已挂载且无 loading/error 骨架」才移除 `is-boot-loading`）。

新版首页 `HomeView.vue` 的根节点是 `.home-view`，**不使用该 class** → 判定永远不成立 → 即使 4 秒超时兜底也只是重新排帧、`doneFrames` 仍为 0 → `is-boot-loading` 永不移除 → 它携带的 `overflow-y: hidden` 一直生效。

| 项 | 数据 |
| --- | --- |
| 症状 | 浏览器「截取整个页面」只能得到一屏（1920×900），中间区域单独长截图正常 |
| 根因 | `document.documentElement.scrollHeight === 900`（等于视口高），整页截图工具认为页面只有一屏 |
| 实际滚动容器 | `.app-container`（`scrollHeight 1665` / `clientHeight 900`，可滚 765px） |
| 判定修正 | 加兜底 `document.querySelector('.app-main > *:not(.ui-modal-host)')` |

修复后 `/`、`/items`、`/sims`、`/misc` 四条路由实测 `is-boot-loading` 均正常移除，`app.scrollTop` 可正常写入 400。

> **未改变滚动架构**：`.app-container` 仍是唯一滚动容器，`html/body` 依旧 `overflow: hidden`。整页长截图需临时解锁（见 `docs/context/technical/HOME_CONTENT.md` §十）。

### 公告弹窗一天多条只弹一次

原逻辑用 `date`（天粒度）作去重键，同日发第二条时 `date` 未变 → 不再弹窗。

| 改动 | 内容 |
| --- | --- |
| 去重键 | `date` → `id`（无 id 时回落 `date#title`） |
| 已读存储 | `lastNoticeDate`（单条）→ `lastNoticeKey`（**集合**，JSON 数组，上限 50 条） |
| 旧数据兼容 | 保留读取 `lastNoticeDate`，首次写入新键时清除旧键 |

已验证四种场景：首次弹出 / 已读不重弹 / 同日新增能弹 / 旧记录兼容不弹。

### 公告列表顺序

改为「置顶项固定在前 → 其余按 `date` 倒序（最新在上）→ 同日保持 JSON 书写顺序」。

## 首页 UI 细节调优（已合入主页）

### 1. 核心图鉴与实用工具标题（方案 4 卷轴羽化刻度线）
- 标题文案精简：“核心图鉴检索”简化为“核心图鉴”，“实用模拟与策略工具”简化为“实用工具”，去掉后方副标题说明文本；
- 标题衬底宽度微调为 220px，右侧半透明羽化平滑过渡到第 1 与第 2 张卡片间隙处，兼顾古籍卷轴意境与版面透气度。

### 2. 核心图鉴图标容器（方案 A 无界透光大图标）
- 彻底移除原版带有脏感凹陷内阴影的灰色细圆圈边框（`border: none; box-shadow: none`）；
- 图标尺寸由 32px 提升至 42px，底层衬以温和径向暖金微光；
- 悬停交互：鼠标移入卡片时图标微弹跳放大（`scale: 1.12`），微光适度提亮，视觉呼吸感与开阔感显著增强。

### 3. 焦点海报左右翻页箭头（TapTap 官方 1:1 复刻）
- 结构与尺寸：由 32×40px 方块重构为 28×64px 纤细圆角胶囊（`border-radius: 8px`，暗色毛玻璃 `rgba(0,0,0,0.58)` + `blur(12px)`）；
- 内部矢量图标：引入 TapTap 原版 8×23px 细线条圆角 SVG 箭头（杜绝字体字符走样）；
- 纯净交互规范：
  - 常态下完全隐藏（`opacity: 0`），鼠标移入海报区域平滑淡入（离开海报带 0.7s 优雅退场延时，不闪烁）；
  - 悬停于箭头按钮上时，**黑色胶囊底托与阴影完全静止不变**（不放大、不加深、不重绘），**仅内部箭头图标独立放大至 1.18 倍并高亮纯白**，实现 60fps 硬件加速流畅动效。

### 4. 焦点海报无缝无限循环滑轨（Swiper / TapTap 机制）
- **动效架构升级**：告别原版透明度淡入淡出（crossfade），升级为水平物理滑轨（`flex` + `translate3d(-X%, 0, 0)`），搭配 `0.45s cubic-bezier(0.16, 1, 0.3, 1)` 丝滑阻尼曲线。
- **无感静默回跳（Infinite Loop）**：
  - 构造 `[尾项克隆, ...真实海报, 首项克隆]` 共 5 项虚拟滑轨，首屏落在索引 1；
  - 向后翻到最后一页再点击时，视觉上继续平滑右滑进入首项克隆海报，待动画结束（`transitionend`）静默（`transition: none`）瞬切回索引 1 真实海报，彻底解决从末页倒带倒退回首屏的违和感；
  - 往前翻到首张再往前同理逆向静默瞬切；
  - 资源与性能安全：固定 5 个 DOM 节点，图片直接复用内存缓存（0 次重复请求），位移动画完全由 GPU 合成器接管，不触发 layout/reflow。

### 5. 焦点海报行动按钮（方案 7 无框微光流线文本链）
- 彻底移除原版突兀的黄色实心矩形色块底托，升级为画册级纯文字排印（`13.5px / 700`）+ 独立圆形微光箭头 `( > )`；
- 底部衬以向右羽化渐隐的暗金渐变流光细线（`linear-gradient(90deg, #d4a74a, transparent)`）；
- 悬停动效：箭头平滑右移 4px 并注入金色高光，整行文字透出温润白金微光，完全不遮挡海报立绘。

### 6. 焦点海报指示点（方案 E 深渊符石晶菱·微调透亮版）
- 纯 CSS 45° 旋转晶核形态（`6px × 6px`，尖角间距 ~6.8px），呼应《深渊之歌》符石秘境与魔导晶石世界观；
- 激活项采用透亮的水晶青渐变（`linear-gradient(135deg, #74deda, #4ea8a4)`）搭配白金切面棱线与 `6px` 柔和深渊青辉光；未激活项为半透晶石线框（`◇`）；
- 纯 CSS 矢量渲染，0 网络请求，全端视网膜级锐利且具备硬件加速呼吸动效。

### 7. 实用工具图标容器（方案 5 微光透气圆座 + 42px 大图标合体版）
- 彻底移除原版死黑泥质方框（`#44301d → #2b1d11` 实心渐变块 + 深褐硬边框），消除羊皮纸卡片上的违和暗洞感；
- 继承核心图鉴一致的设计语言：采用温和的金色漫反射圆座光晕（`radial-gradient(circle, rgba(198, 146, 52, 0.22) 0%, transparent 74%)`），实现版面呼吸感与透光统一；
- 图标尺寸由原先被压制的 28px 舒展放大至 **42px 满格原画尺寸**，配合立体下沉投影（`filter: drop-shadow(0 3px 6px rgba(43, 31, 21, 0.35))`）；
- 悬停动效：移入卡片时光晕适度提亮，图标轻量上浮 2px 并微缩放 1.08 倍，视觉生动且富有层次。
