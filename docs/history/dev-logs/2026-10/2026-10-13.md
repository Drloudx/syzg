# 2026-10-13 开发汇总

## UI 与交互
- **后台管理系统 (`/admin`) 全面消除原生系统弹窗**：

  - **评论审核面板 (`AdminCommentsPanel.vue`)**：
    - 将单条放行/隐藏、批量放行/隐藏、彻底删除评论等全部确认操作替换为统一 `UiModal` 确认弹窗。
    - 弹出层完整呈现原正文摘录、影响范围（所有人可见 / 仅作者本人可见）与不可逆提醒。
  - **系统设置面板 (`AdminSettingsPanel.vue`)**：
    - 将新建敏感词类别的原生 `window.prompt` 替换为 `UiModal` 输入弹窗，自带输入验证、字数实时统计与错误提示。
- **后台分页条全面改版为主流折叠跳页分页器（用户管理 & 评论审核）**：
  - **折叠展示**：支持首页（1）、当前页附近几页（当前页 ± 2 页）、尾页，跨度较大时显示省略号 `…` 进行折叠，彻底解决页数多时全量平铺拥挤的问题。
  - **快捷跳转**：提供 `跳至 [ ] 页 [确定]` 跳转输入框，支持输入任意有效页码后回车或点击跳转。
  - **服务端分页能力支持**：
    - `functions/api/[[path]].js` 的 `adminUsers` 和 `adminList` 端点新增对 `page` 参数的支持，统一计算总记录数 `total`、总页数 `totalPages` 并使用 `LIMIT ? OFFSET ?` 切片返回。
    - `src/utils/adminApi.js` 同步支持 `page` 参数传递。

- **权限验证闸门页 (`AdminView.vue` Gate) 全面美化与对比度修复**：
  - 将原本裸露的大背景文字改版为手造复古皮质卡片（`.leather-panel-container`），内衬双线边框、青铜金锁徽章与典雅标题；
  - 彻底重构底部报错横幅（`.admin-gate-error-banner`），采用高对比度深红警示色（`#b83232`，暗色下 `#f07f7f`）与警示图标，彻底解决此前淡粉色字体在浅土黄背景下“看不清楚”的问题；
  - 按钮增加黑胡桃金边按钮（`.admin-btn--gold`），与后台整体视觉完全统一。
- **修复后台分页 API `whereClause` 块级作用域变量未定义报错**：
  - 在 `functions/api/[[path]].js` 的 `adminUsers` 与 `adminList` 中，修复了 `const whereClause` 在 `if (total === null)` 块内声明导致块外 SQL 拼装时抛出 `ReferenceError: whereClause is not defined` 触发 500（“无法连接评论服务器”）的问题。
  - 声明提升至 `isPageMode` 函数块顶层，并针对 `binds` 为空时进行安全调用防御。
  - 用户端恢复正常毫秒级极速响应，跳页与数据渲染恢复正常。

- **移除表格跳页加载遮罩（恢复为直接切换）**：
  - 响应用户交互体验反馈，移除用户管理 (`AdminUsersPanel.vue`) 与评论管理 (`AdminCommentsPanel.vue`) 表格上层的半透明遮罩与加载转圈动画；
  - 保持后台跳页时的无缝平滑替换，避免视觉打断。
- **表格最后一行视觉修正与翻页滚动重置**：
  - 修复 `AdminCommentsPanel.vue`、`AdminUsersPanel.vue` 和 `AdminAuditPanel.vue` 表格最后一行（`tbody tr:last-child td`）的虚线底边与容器实线边框重叠问题；
  - 切换页码时自动平滑重置滚动视口至顶部，消除跨页行高差异导致的被遮挡或截断问题。
- **评论审核状态 Tab 全量展示分类数量**：
  - 在 `AdminCommentsPanel.vue` 中，「待审」、「已显示」、「已隐藏」、「全部」各 Tab 均展示对应的评论数量统计，如 `待审 (201)`、`已显示 (2890)`、`已隐藏 (56)`、`全部 (3147)`；
  - 服务端 `adminList` 端点在首屏聚合返回 `statusCounts`。
- **审计日志面板全面升级为主流跳页分页器 (`AdminAuditPanel.vue`)**：
  - 将旧版“加载更多”按钮重构为主流数字折叠跳页分页器（上一页、页码折叠、下一页、指定页跳转）；
  - `functions/api/[[path]].js` 的 `adminAuditList` 端点增加 `page` 参数支持，支持 `LIMIT OFFSET` 与总记录数统计。

- **后台表格布局采用工业级方案 A 重构（满屏自适应 + 内部滚动 + 表头吸顶 + 分页底栏固定）**：
  - 彻底解决此前页面级混用外层滚动导致的表格高度不统一、底部分页栏遮挡内容截断文字半截的问题；
  - `AdminCommentsPanel.vue`、`AdminAuditPanel.vue`、`AdminUsersPanel.vue`：
    - 主卡片根容器设为 `height: 100%; display: flex; flex-direction: column; overflow: hidden;`；
    - 顶部工具栏与筛选区 `flex-shrink: 0`；
    - 中间表格容器 `.table-container` 设置 `flex: 1; min-height: 0; overflow-y: auto;`；
    - 表头 `thead th` 采用 `position: sticky; top: 0; z-index: 2` 吸顶，在表格滚动时稳固吸顶；
    - 底部分页栏 `margin-top: auto; flex-shrink: 0` 永远固定在卡片底部，绝不上浮遮挡内容，最后一行可以完整滚动露出；
  - `AdminOverviewPanel.vue` 与 `AdminSettingsPanel.vue` 同步改造为满高容器，内部平滑自适应滚动。
- **后台页面全新设计定制专属复古滚动条 (`AdminView.vue`)**：
  - 消除 Windows 系统默认粗大突兀且带有上下三角箭头的 15px 灰白滚动条；
  - 规避全局 `theme.css` 中 `* { scrollbar-color: ... }` 压制 WebKit 伪元素的 Chromium 特性，在 `.admin-shell` 下精准重置并定制专属样式；
  - 滚动条宽度收窄为精细的 6px，彻底移除上下方向三角按钮（`::-webkit-scrollbar-button { display: none !important; }`）；
  - 浅色模式采用半透明羊皮纸底轨与黄铜金棕滑块（hover 高亮），暗黑模式采用深深胡桃木色与黄铜光泽，与后台复古羊皮纸视觉风格浑然一体。
- **修复评论审核翻页后待审数量变 0 的问题 (`functions/api/[[path]].js` & `AdminCommentsPanel.vue`)**：
  - 根因分析：此前服务端仅在 `pageNum === 1` 时计算状态聚合，而在 `pageNum > 1` 时直接返回 `pendingCount: 0`；前端接收后无条件将 `statusCounts['0']` 覆盖为 0，导致翻页后 Tab 显示为 `待审（0）`；
  - 解决方案：
    - 服务端 `adminList` 在分页模式下每页统一通过 `GROUP BY status` 返回实时的 `statusCounts` 与 `pendingCount`；
    - 前端优先同步完整 `statusCounts`，并防御性地确保在未收到新计数时不被 0 错误冲刷。
- **后台侧栏底部快捷入口视觉改版 (`AdminView.vue`)**：
  - 移除原旧版「📖 前台图鉴总览」与「💬 公开讨论区」的 emoji 图标；
  - 前缀替换为与顶部栏右上角同款的向左微动箭头（`<svg>` 细线条，hover 时轻微向左位移）；
  - 文案统一更新为「前往首页」与「前往讨论区」，贴合后台导航习惯。
- **表格翻页后滚动条自动回到顶部 (`AdminCommentsPanel.vue`, `AdminAuditPanel.vue`, `AdminUsersPanel.vue`)**：
  - 解决此前重构方案 A 后，外层 `.admin-body` 滚动重置已失效、而表格容器内部依然保留底部滚动偏移的问题；
  - 在翻页（点击上一页、下一页、页码或输入跳页）和重置筛选时，精确将当前面板的 `.table-container` 之 `scrollTop` 置零，确保新一页数据始终从第一行开始清晰呈现。
- **修复用户管理指标卡等处人员 SVG 小人头部变形乱线问题**：
  - 排查发现原路径贝塞尔曲线参数存在拼写偏差，导致小人头部闭合路径横穿面部产生尖刺乱线；

    - 彻底解决新建敏感词类别弹窗中输入框因未声明宽度导致过短截断的问题，设置 `width: 100% !important; display: block;` 自适应充满弹窗。
  - **筛选标签（Chips）美化**：
    - 未选中项采用柔和半透明羊皮纸胶囊底衬（`rgba(255, 255, 255, 0.55)`）与古金细边，hover 平滑高亮；

    - 评论搜索按钮与输入框高度 34px 精确对齐，升级为黑胡桃金边复古按钮。
- **控制台概览新增今日/昨日环比双环饼图与满屏免滚动优化 (`AdminOverviewPanel.vue`, `functions/api/[[path]].js`)**：
  - **已登录活跃用户与评论对比环**：

    - **顶部指标卡片支持整卡直达跳转**：今日评论 → 直达全部评论列表（`?status=all`）、待审核 → 直达待审列表（`?status=0`）、注册用户 → 直达用户管理，右上角增加复古微动斜箭头 `↗`；
    - **修复评论跳转筛选状态同步问题 (`AdminCommentsPanel.vue`, `AdminOverviewPanel.vue`)**：
      - 解决从控制台「今日评论」或从用户管理点击「用户评论数」跳转过来时，界面仍停留在默认「待审」的问题；

      - 后端补齐 `userOnly`（`u.role = 0`）精准条件分支，选择「普通用户」时准确过滤掉全部管理员与超级管理员。

    - **后台管理系统全套手机端 / 移动窄屏响应式适配 (`AdminView.vue`, `AdminUsersPanel.vue`, `AdminCommentsPanel.vue`, `AdminOverviewPanel.vue`, `AdminAuditPanel.vue`, `AdminSettingsPanel.vue`)**：
