## 站点统计

- **接入百度统计（站点 ID `2c323f…`）**：官方代码为内联 `<script>`，与本站 CSP `script-src 'self'`（禁止内联）冲突，改为**同源外部加载器** `public/baidu-analytics.js`（`defer` + 动态 `async` 注入 `hm.js`），`index.html` 在 `</head>` 前以 `defer` 引入。
  - 加载器只在 `location.hostname === 'syzgwiki.top'` 时注入，`localhost` / `pages.dev` 预览 / Android 原生壳（`https://localhost`）均不加载，避免污染 Web 数据。
  - `public/_headers` 的 CSP 放行 `hm.baidu.com`（`script-src` / `img-src` / `connect-src`），并同步更新头注释说明内联脚本仍为 0。
  - 实测对首屏无影响：DOMContentLoaded 中位 232ms vs 阻断时 225ms（+7ms，噪声级）。
