# 2026-11-10 开发日志

## 一、魔物图鉴（/pets）特性表格排版与视觉优化

### 1. 改动背景
用户反馈魔物图鉴中的「特性表格」视图排版不协调，存在表头与筛选面板间距缝隙、魔物名字缺少立绘图标且存在变异小图标杂质、1~7 级数值区间包含冗余汉字且多项数值未换行等问题。

### 2. 具体调整
- **魔物列视觉升级**：
  - 移除魔物名称右侧的变异菱形图标；
  - 在魔物名称左侧新增魔物专属小头像（`PicHandBookPanel_Atlas` 32×32px 微圆角质感框）；
  - 魔物名称采用各星级专属品质色与 700 字重，单行平整排列不折行。
- **1 级 → 7 级纯数值清洗与多行展示**：
  - 新增 `getPetRanges(pet)` 格式化处理，剔除「魔法攻击」「物理攻击」等中文文字，只保留纯数值区间（如 `500% → 1100%`、`100% → 180%`）；
  - 存在多组数值变化（如宝石迷迷可、格里芬、洛莉安的眷属）时，拆分为独立数组，以青墨色气泡小标签多行竖向换行排版。
- **表头衔接与结构复刻魔物收益页**：
  - 将表头按魔物收益页（PetsEggsView）方案放回顶部筛选面板的 `#footer` 内，完全移除非法负边距（`-14px`），保持四周内边距规整端庄；
  - 表头采用微凹木色条（`border-radius: 4px; box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.22), 0 1px 3px rgba(62, 42, 20, 0.12)`），与筛选栏及下方表格行自然对齐；
  - 颜色全面降噪压暗：魔物名称采用深金褐、深靛青等深色调，星级采用古铜木色，属性采用深群青、深砖红、墨绿和深赭石，区间采用温润羊皮纸底框，彻底消除亮色刺眼问题；
- **视图切换组件样式统一（对齐装备图鉴）**：
  - 将右上角「图文 / 特性表格」模式切换按钮容器与按钮样式完全对齐 `EquipsView.vue`（浅色羊皮纸底框，激活态采用白底 `var(--paper-solid)`、青墨字 `var(--accent-ink)` 与微投影）；
- **星级文字颜色规范对齐（魔物收益页）**：
  - 星级单元格绑定 `quality-text-${pet.starDisplay}`，5 星魔物呈现暖金褐色（`var(--q5-text)`），4 星呈紫色（`var(--q4-text)`），3 星呈蓝色（`var(--q3-text)`），与魔物收益页面弹窗及筛选区保持统一视觉色彩；
- **星级游戏内真实映射修复**：
  - 将表格中星级字段由原始配置 `pet.star` 修正为游戏实际展示映射字段 `pet.starDisplay`（即 `star + 2`，1~3 星映射为 3★/4★/5★）；
- **移动端窄屏精简（3 列自适应展示）**：
  - 媒体查询 `@media (max-width: 768px)` 中对星级、属性、特性名列进行隐藏（`display: none !important`）；
  - 手机端仅保留「魔物（头像+名字）」、「特性效果（满级 7 级）」与「1 级 → 7 级纯数值」三列，去除横向拖动限制，排版舒展大气；
- **划到底部对齐与左右两栏平齐修复**：
  - 调整 `.pets-page` 的高度约束，由强制固定 `height: 100%` 改为 `min-height: 100%`，并在 `.pets-table-scroll` 底部保留 `20px` 边距；
  - 划到底部时，中间魔物表格卡片的圆角底边与左侧导航栏、右侧看板娘停靠基线绝对平齐，羊皮纸底图间隙完全显露，不再被切断。

### 3. 验证情况
- 实机截图核验：
  - 桌面端：`preview_pets_table_fixed.png`；
  - 移动端：`preview_pets_table_mobile.png`。
- 测试回归：全套 454 项单元测试全绿（`tests: 454 passed`）。

## 二、魔物详情移动端好感度转化分行适配

### 1. 改动背景
移动端窄屏（抽屉/全屏弹窗）宽度受限，魔物详情中「好感相关」模块第 3 格「上场加时转化」因右侧数值文本长达 8 个字符（如 `1秒 / 10好感`），水平两端对齐时右侧被压缩为竖排多行文本（`1秒` / `/ 1` / `0好` / `感`），导致该格及右侧相邻格高度被异常拉伸，下部产生大量空洞。

### 2. 具体调整
- **UiStatGrid 组件能力扩展**：
  - 属性项支持 `stacked` 与 `stackedMobile` 配置属性；
  - 媒体查询 `@media (max-width: 768px)` 下，对标记 `is-stacked-mobile` 的单元格自动切换为纵向排布（`flex-direction: column; align-items: flex-start; justify-content: center; gap: 3px;`），同时设置 `white-space: nowrap` 禁止文字拆散折行；
  - 单元格默认垂直对齐由 `baseline` 优化为 `center`，确保当某列分行撑高时，同行的单行单元格（如「抚摸增加好感 +5」）自动垂直居中，布局工整。
- **PetsView 移动端好感度项配置**：
  - 在「好感相关」模块中为「上场加时转化」项添加 `stackedMobile: true`；
  - 仅在手机端生效为上下两行展示（上行标签、下行数值），桌面端宽屏依然保持单行两端对齐。

### 3. 验证情况
- 实机截图核验：
  - 移动端：`preview_favor_after_mobile.png`（「上场加时转化」上行标签、下行数值，平整无折行，相邻格垂直居中）；
  - 桌面端：`preview_favor_after_desktop.png`（保持单行横向对齐）。
- 单元测试：454 项全绿通过。
