# 2026-11-16 开发汇总

## UI 与交互
- **探索与事件奖励组件重构（`src/views/EventsView.vue`）**：
  - 奖励区由单卡片列表迁移至全站统一的 `RewardPools.vue` 货架布局，支持品质边框、右上角综合概率角标与悬停详细信息。
  - 探索区域标题与弹窗引用文案调整为「预估探索奖励」。
  - 探索货架支持 `hide-prob`：外部卡片只保留右下角「预估数量范围」，移除右上角打架的黑标签概率（100%、82% 等）；综合概率与单次概率统一收敛至悬停 Tooltip 与「概率明细」弹窗中，界面清爽统一。
  - 标题栏右侧接入 `.prob-detail-btn`「概率明细」按钮，点击呼出全局 `RewardProbabilityModal`。
  - 弹窗明细模式（`breakdown = true`）与外部货架彻底分层：明细模式下展示底层配置表单次抽取区间（`rawMin` / `rawMax`，如木材 40~60），非区间规则自动隐藏冗余的“均等概率”占位，避免产生多轮重复叠加倍数的歧义。
  - 修复探索点位与遭遇敌人标签（`positions`、`enemys`）缺少弹性容器导致的紧贴贴边现象（新增 `.event-map-tags` 容器，`gap: 6px`）。

## 数据与解析
- **探索奖励解析规范（`src/utils/eventData.js`、`src/utils/acquisitionRules.js`）**：
  - 新增 `parseExploreRewardEntries`：区分主材组（固定轮数累计区间，如木材 2 轮累计 80~120）与多选一候选池组。
  - 候选池多项产出改用二项分布高概率核心波动区间（$\mu \pm 1.25\sigma$），向玩家准确呈现单次挂机探索的预估数量范围（如小麦 3~7、亚麻 1~4）。
  - 条目契约同时保留 `rawMin`/`rawMax`（底层单次抽查数值）与 `min`/`max`（整场预估范围）。
  - 导出 `parseRewardGroups` 供事件图鉴使用；`acquisitionRules.parseRewardEntries` 增加奖励池字段，保持向下兼容。
  - 预解析产物 `public/data/parsed/events.json` 重新生成。
