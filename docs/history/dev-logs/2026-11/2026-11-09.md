## 装备词条（可携带效果）解析修复

5 星装备详情页「可携带效果」整块为空。根因是**词缀 key 与 skillTrigger id 不是一回事**：

- `itemAffixes.json` 里存的是 `prefixPool` 的键，如 `equip_sp0201_2` / `equip_001`。
- `equipGlobalConfig.prefixPool[key]` → `{ skillTriggerId, level, name }`。
- 描述在 `skillTrigger[skillTriggerId].levelData[level].des`；`equip_XXX` 一类另需
  `buff[skillTriggerId_level_buff].buffDes` 兜底。

旧实现直接 `cachedSkillTriggers[prefixId]`，永远查不到 → 全部渲染为 `null`。

| 项 | 修正 |
| --- | --- |
| 解析入口 | `parseItemAffixes` 先查 `prefixPool` 拆出 triggerId + level，再取对应档描述 |
| 兜底 | 无 `levelData.des` 时读 buff 表的 `buffDes` |
| 覆盖 | 正式 5 星装备 18/18 可解析；其余 6 件为测试/时装类，官方无词条 |

## 章节地图：统一各章缩放

`RegionRouteMap` 的初始缩放原本按**本章自己的节点范围**贴合（`min(视口/本章范围)×1.4`），
关卡少的章被放得明显更大：实测 c0 88% / c1 63% / c2 56% / c3 54%，章与章没法横向比较。
1.7.15 把序章从 5 关压到 3 关后，c0 的节点范围更扁更窄，这个差异被放大、一眼可见。

改法：地区路线图初始缩放**固定为 65%**（`REGION_FIXED_ZOOM = 0.65`），各章只按自身节点范围
居中。改后四章同为 **65%**，关卡石台像素尺寸一致（83px），c1 依然完整可见。

> 中途曾用「所有可见章节节点范围的并集」算统一缩放（得到 52%），按用户要求改为固定 65%。

- 只统计**可见章节**（c0~c3）；黑名单章（c4/c5/sp1/sp2）不参与。
- `fixedZoom` 缺省（≤0）时退回旧的「按本章贴合」，组件单独使用时行为不变。
- 涉及 `src/views/ChaptersView.vue`（`REGION_FIXED_ZOOM`）、`src/components/chapters/RegionRouteMap.vue`（`boundsOf` / `nodeBounds` / `selfBounds` / `resetView`）。
