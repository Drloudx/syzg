# 2026-11-04 开发汇总

## UI 与交互
- **全局非图鉴怪物详情弹窗支持**：
  - 关卡、副本、日常计划中点击非官方图鉴怪物（如治安队员、人贩子、巨木侍女等）时，不再报错，可无缝呼出全局 `MonsterDetailModal`。
  - 属性面板联动等级滑块（1~80 级），自动带入当前关卡/副本的推荐等级作为默认初始等级。
  - 优先匹配官方图鉴大立绘（`colect_mon_`，已覆盖 212 种）；无立绘的杂兵自动回退到圆框头像（`HeadIconAtals`，带金色边框与柔和底衬，消除黑洞空图）。
  - 展示完整技能机制（普攻/技能名、CD、伤害倍率、段数、附加 Buff），省略图鉴 Lore 文案与关卡掉落区。
- **房间特殊战斗机制卡片（增援 / 破盾 / 坚守）**：
  - 在 `RoomContentList.vue` 中支持结构化展示房间特殊机制，风格参考技能面板召唤物（无 Emoji、大书院古典书卷金边框 + 棕红引导线）。
  - **持续增援 / 坚守模式**：结构化展示刷新间隔与循环规则，增援单位采用带头像、名称、数量与 `→` 箭头的标准可点击怪物胶囊，点击直接唤起该增援怪的属性与技能弹窗。
  - **破盾 / 减伤机制**：以 2-9 禅心林 Boss 战为例，明确写明 Boss 初始获得「神圣之力」增益，受到伤害降低 99%，破解目标为场景「神秘红晶」，破坏后永久解除 99% 减伤。
- **回滚试验性全怪物图鉴**：
  - 彻底回滚 `MonstersView.vue`，怪物图鉴主页保持官方 52 种正式魔物的纯净与高品质。

## 数据与解析
- `scripts/parse/roomMechanics.mjs`：
  - 新增房间特殊战斗机制解析器，扫描 `room.json` 中的 `triggers`，自动识别 `damageReduce`（减伤/破盾）、`reinforcement`（循环增援/解谜坚守）。
  - 联动 `mon.json` 与 `buff.json`，自动提取减伤百分比（如 `zhuxian2_9` 的 99% 减伤）与增援怪的真实名称与头像。
- `scripts/parse/chapters.mjs` & `src/utils/dungeonData.js` & `scripts/parse/compact.mjs`：
  - 关卡与副本房间变体透传 `mechanics` 结构化字段。
- `scripts/parse/monsters.mjs` & `src/utils/monsterParser.js`：
  - 导出并执行 `buildExtraMonsterData`，为 109 种非图鉴怪物构建战斗形态对象（属性、技能、Buff）。
  - 修正作为关卡怪/Boss 出场的伙伴 NPC（如 `hero041_npc` 埃迪蒂）：接入 `chara/Q/hero_${heroNum}.webp` 战斗模型小人图，杜绝错误提取数字贪婪匹配怪物的 `colect_mon_`（如误匹配成 041 安瑟恩单元）。
  - `public/data/parsed/monsters.json` 补充 `extraMonsters` 字段供全局弹层读取，不改变 `monsters` 数组接口。
