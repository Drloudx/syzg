## **配装注意事项：**

1. 3 个法师的武器带湖晶法杖/吞噬者权杖都行，不过德莉和缇莎带**荆棘前缀的湖晶法杖**更好些，这个词条普攻可以加技能伤害，可以稍微提升一下这俩角色的伤害。
2. 乌尔勒带**湖晶短匕**是因为这个武器加的攻击最多；由于召唤物吃不到角色的攻速加成，因此不带鸟羽弓。同理，乌尔勒的召唤物也无法吃到角色的火伤加成，因此符刻石像鬼的面盔（火伤头）的火伤无法给到召唤物，只有乌尔勒自身的普攻和二技能可以吃到。

# **二、队伍核心与原理**

**队伍核心：圣骑士史莱姆特性 + 缇莎星阶 4「地脉潜能」**

1. **圣骑士史莱姆特性**：全队召唤物均可吃到加成，德莉、安娜、乌尔勒三名角色可提供海量召唤物。
2. **缇莎星阶 4「地脉潜能」**：作用范围是**全体友方**，所以场上的所有召唤物都能吃到。缇莎释放技能后，全队召唤物都可以造成缇莎 **60% 魔法攻击** 加成的额外魔法伤害。
   - 因此给缇莎的武器和手套带攻速符石，并搭配源泉猫特性提升攻速，可快速打满被动，以此触发星阶 3 的减少技能 CD，从而更快、更频繁地打出星阶 4 的额外伤害。
3. 因为乌尔勒没有比较契合的特性，所以将圣骑士史莱姆给乌尔勒携带，顺便让她本体也能吃到增伤，如果队伍有其他人带圣骑士史莱姆的话，可以给乌尔勒带**角布林**。

# **三、召唤物相关机制**

1. 召唤物可继承的数值只有 **物理攻击**、**魔法攻击**、**物理防御**、**魔法防御** 和 **生命值** 共 5 项属性（**德莉召唤物除外，德莉召唤物可继承魔法穿透属性**），其余属性均不继承。召唤物拥有自己的基础暴击、爆伤等属性。
2. 召唤物继承的属性为召唤瞬间的角色属性快照（即召唤时角色当前的实时属性）。
3. 召唤物可以吃全体增益buff。
