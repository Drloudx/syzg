# Bug 反馈：蜘蛛统御头冠「育母」词缀幼体生成数量异常（描述为 2 只，实机仅生成 1 只）

> **最新核对版本**：**1.7.15**（当前线上最新公测版，热更包 `codeVersion: 4F865D05BF6E82751B8FBDEFD2777DC4`）  
> **核对日期**：2026-11-16  
> **类型**：客户端逻辑 Bug  
> **状态**：**1.7.15 最新版本依然存在，尚未修复**  

---

## 一、现象

穿戴「蜘蛛统御头冠」（`item_442001`）或其他携带「育母」词缀（`equip_006`）的装备时：

**装备描述明确说明孵化为 2 只砂蜘蛛幼体，但在实机战斗中蛛卵破裂后永远只生成 1 只幼体。**

| 项 | 表现 |
|---|---|
| 装备技能描述 | 「每 3 次攻击，释放一枚蛛卵，蛛卵 1 秒后会孵化为 **2 只**砂蜘蛛幼体。」 |
| 实机触发蛛卵 | 正常落地单枚蛛卵（砂蜘蛛的蛋），1 秒后正常破壳孵化 |
| 孵化生成幼体 | 场上**仅出现 1 只**砂蜘蛛幼体（附带自爆技能） |
| 战斗实际收益 | 幼体自爆伤害、承伤挡刀、光环收益等直接**腰斩减半**，严重低于装备设计强度 |

---

## 二、复现步骤

1. 穿戴 **蜘蛛统御头冠**（`item_442001`，携带「育母」暗金词缀）；
2. 进入任意战斗副本；
3. 角色进行普通攻击累计达到 3 次，角色身旁地面出现一枚蛛卵（砂蜘蛛的蛋）；
4. 等待 1 秒蛛卵破裂孵化 —— 场上**仅有 1 只**砂蜘蛛幼体出现。

---

## 三、配置核对

排查比对配置表，**在文本与底层 Buff 参数中均明确配置为 2 只**：

```
skillTrigger.json [equip_006]
  {
    "skillId": "equip_006",
    "skillName": "育母",
    "des": "每 {3} 次攻击，释放一枚蛛卵，蛛卵 {1} 秒后会孵化为 {2} 只砂蜘蛛幼体。",
    "buffId": "equip_006_1"
  }

buff.json [equip_006_1]
  {
    "buffName": "育母",
    "buffEffect": "equip_00601",
    "para": {
      "atkCount": 3,
      "monCount": 2,                 ← 明确配置目标数量为 2 只！
      "hpAdd": 0.1,
      "egg": {
        "time": 1,
        "mon": "013_egg",
        "bulletId": "1308"
      },
      "eggs": {
        "time": 1,
        "mon": "013_eggs",
        "bulletId": 1309
      },
      "mon": "013_baby",
      "monTime": 5
    }
  }
```

**结论：设计意图确为召唤 2 只幼体，配置表参数完全一致，问题出在客户端程序代码。**

## 四、客户端根因定位

在 **`Equip_00601Buff.cs`** 中存在一处硬编码的数值截断判定。

### ① 致命判定代码：将非 1 非 3 的数值强行重置为 1

在最新 1.7.15 客户端源码 `Equip_00601Buff.cs` **第 135~150 行**：

```csharp
// Equip_00601Buff.cs 第 135 行
if (monCount != 1 && monCount != 3)
{
    monCount = 1;    // ⚠ 截断点：若不是 1 也不是 3，强行重置为 1！
}

if (monCount == 1)
{
    // 生成单颗蛋 013_egg
    CreatEgg(eggInfo["mon"], Vector2.op_Implicit(zero2), float.Parse(eggInfo["time"]), 1, eggInfo["bulletId"]);
}
else
{
    // 生成连体卵簇 013_eggs
    CreatEgg(eggsInfo["mon"], Vector2.op_Implicit(zero2), float.Parse(eggInfo["time"]), 3, eggInfo["bulletId"]);
}
```

**冲突过程**：
1. 在编写 `Equip_00601Buff.cs` 时，只做了单颗蛋（`monCount == 1`）和连体卵簇（`monCount == 3`）两个分支；
2. 当 `buff.json` 中配置的 **`"monCount": 2`** 传入时：
   `2 != 1 && 2 != 3` 判定命中为 `true`；
3. **`monCount` 在第 137 行被强制赋值覆盖为 `1`**；
4. 随后 `if (monCount == 1)` 命中，程序调用了 `CreatEgg(eggInfo["mon"], ...)`，在场上仅生成了单颗蛋（`013_egg`）。

---

### ② 蛛卵孵化逻辑：单颗蛋本身只配了孵化 1 只

生成的单颗蛋（`013_egg`）在 1 秒后孵化，执行其绑定的技能 `mon_013_egg01`：

- **技能表 `raw/skill.json` [mon_013_egg01]**：
  ```json
  "aniEvents": [
    {
      "eventName": "birth",
      "arg": {
        "cnt": 1,                    ← 单蛋技能自带数量仅为 1 只！
        "mons": ["013_baby"],
        "delay": 8,
        "hp": 0.1
      }
    }
  ]
  ```
- **源码 `SandSpiderEgg.cs`（第 65 行）**：
  ```csharp
  // cnt 读取自技能配置中的 1
  for (int i = 0; (float)i < cnt; i++)
  {
      BattleManager.instance.CreatSummon(...); // 实例化砂蜘蛛幼体 013_baby
  }
  ```

由于蛋本身是单蛋模型 `013_egg`，其自带技能参数 `cnt` 亦为 1，因此在实机战斗中**最终只能孵化出 1 只砂蜘蛛幼体**。

## 五、影响范围

1. **涉及装备**：
   - 2 阶暗金头部：**蜘蛛统御头冠**（`item_442001`）；
   - 其他任意随机洗炼出 **「育母」**（`equip_006`）词缀的装备。
2. **战斗表现受损**：
   - 幼体实机数量腰斩（原本期望 2 只，实际仅 1 只）。
