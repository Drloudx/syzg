## 二、 漏修代码精确定位

### 1. `UnitAttribute.SetPenetrationFromPercent()` 方法体漏写 `/ 100f`

`UnitAttribute.cs` 已将英雄、PvP 英雄、普通/精英怪物、出战魔物全部 5 个初始化入口（第 452、550、649、700、765 行）统一收敛到 `SetPenetrationFromPercent(...)`，但该函数自身仍直接原样赋值：

```csharp
// UnitAttribute.cs 第 380~384 行
private void SetPenetrationFromPercent(float physicalPercent, float magicPercent)
{
    phyAtkPen = physicalPercent;   // ❌ 传入百分数 2f，未写 / 100f
    magicAtkPen = magicPercent;    // ❌ 存进 unitData 仍是 2f，而非 0.02f
}
```

以湖晶法杖（`item.json` 配置 `"magicAtkPen": 2`）或营地研究 1 级（`campResearch.json` 配置 `1`）为例：
- `HeroBattleAttributeGroup.MagicAtkPen` 汇总后仍为百分数 `2f`；
- 经第 452 行调用 `SetPenetrationFromPercent(...)` 后，`unitData.magicAtkPen` 依然是 **`2f`**。

### 2. 活动法盘属性注入同源未除以 `100f`

```csharp
// BattleManager.cs 第 13205~13206 行（InitSpRelicHeroAddAttr）
unitData.phyAtkPen += right.phyAtkPen;     // ❌ right 中来自 skillTrigger 的百分数（如 2f），未写 / 100f
unitData.magicAtkPen += right.magicAtkPen; // ❌ 未写 / 100f
```

*(注：`RelicDetailPanel.cs` 第 46、50 行与 `RelicItemToTalTips.cs` 第 66、67 行展示法盘总属性时均有 `0.01f` / `/ 100f`，说明法盘配置来源确实为百分数。)*

## 三、 当前版本的实机连带后果

由于 `Buff_AttributeAdd.cs` 和 `UnitDataShowPanel.cs` 均已切换到“小数口径”，而 `UnitAttribute.cs` 与法盘注入仍写入“百分数数值”，当前线上会产生以下两个问题：

1. **实战仍触发 `100%` 无视防御**：
   `DamageResolver.cs`（第 120、134、151 行）按小数上限 `1f` 钳位：
   ```csharp
   num8 = ((damageInfo.damageType == "phyAtk") ? self.unitData.phyAtkPen : self.unitData.magicAtkPen); // 取到 2f（或 1f）
   ...
   num8 = Mathf.Min(num8 + damageInfo.ignoreDef, 1f); // Mathf.Min(2f + ignoreDef, 1f) = 1f
   ...
   num14 = num13 / (num13 + num7 * (1f - num8)) * num6; // num7 * (1f - 1f) = 0f（防御归零）
   ```
   德莉（`hero_060`）护卫与彩虹史莱姆（`pet_118`）召唤物通过 `Unit.cs` 第 2122~2129 行按比例继承 `summoner.unitData.magicAtkPen / phyAtkPen`，也会同步拿到 `>= 1f` 触发 100% 穿防。

2. **战斗内详情面板显示放大 100 倍**：
   `UnitDataShowPanel.cs` 第 217~218 行已改用 `GetPercent(curUnit.unitData.phyAtkPen / magicAtkPen)`，而 `GetPercent(value)`（第 223~227 行）会计算 `value * 100f + "%"`。因此 `2%` 穿透进图后会显示为 **`200%`**（`1%` 显示为 **`100%`**）。

## 四、 修复建议

其余已改模块（`HeroBattleAttributeGroup.cs`、`Buff_AttributeAdd.cs`、`UnitDataShowPanel.cs`、`Unit.cs` 召唤物乘法继承）无需回退，只需补齐以下两处 `/ 100f` 即可完成闭环：

1. **`UnitAttribute.cs` 第 380~384 行**：
   ```csharp
   private void SetPenetrationFromPercent(float physicalPercent, float magicPercent)
   {
       phyAtkPen = physicalPercent / 100f;
       magicAtkPen = magicPercent / 100f;
   }
   ```
2. **`BattleManager.cs` 第 13205~13206 行**（`InitSpRelicHeroAddAttr`）：
   ```csharp
   unitData.phyAtkPen += right.phyAtkPen / 100f;
   unitData.magicAtkPen += right.magicAtkPen / 100f;
   ```
