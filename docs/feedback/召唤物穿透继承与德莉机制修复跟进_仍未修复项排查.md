## 二、 召唤物穿透继承体系精确定位

### 1. 德莉护卫连带触发 `100%` 无视魔防

```csharp
// UnitAttribute.cs 第 380~384、452 行（本体初始化未 / 100f，2% 存成 2f）
SetPenetrationFromPercent(heroBattleData.attributeGroup.PhyAtkPen, heroBattleData.attributeGroup.MagicAtkPen);

// Unit.cs 第 2122~2129 行（召唤物初始化直接按比例乘）
if (summonData.magicAtkPenPrecent != 0f)     // 德莉 06002 与 hero060Talent 均填了 1
{
    unitData.magicAtkPen = summoner.unitData.magicAtkPen * summonData.magicAtkPenPrecent; // ❌ 直接拿到 2f
}
if (summonData.phyAtkPenPrecent != 0f)
{
    unitData.phyAtkPen = summoner.unitData.phyAtkPen * summonData.phyAtkPenPrecent;
}
```
随后进入 `DamageResolver.cs` 第 134 行 `Mathf.Min(2f + ignoreDef, 1f) = 1f`，护卫魔伤直接 100% 无视魔防。修复 `UnitAttribute.SetPenetrationFromPercent()` `/ 100f` 后此处不需再改。
