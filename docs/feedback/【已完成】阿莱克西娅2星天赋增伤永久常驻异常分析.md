> **最新核对版本**：**1.7.15**（`cdnVer: 38`，`codeVersion: A0A4112C5087F29074EA0C41AD03EE6F`）  
> **核对日期**：2026-11-24  
> **状态**：**已修复**（`Buff_hero051Skill1.cs` 已在 `EndAction()` 中调用 `ResetTempBuff()` 卸载 `damageBonusBuff`）  
> **类型**：战斗逻辑 / 状态生命周期管理异常（Buff 卸载逻辑缺失）  
> **严重程度**：中高（增伤效果彻底脱离护盾与技能 CD 限制，全程常驻）  
> **关联角色**：阿莱克西娅（Hero 051，神眷之圣女）  

---

## 一、 问题概述

阿莱克西娅（Hero 051）的 2 星天赋【龙力之祝福】设计效果为：
> “对我方单位施加护盾的同时，该单位还会额外获得 {10%/15%/20%/25%} 的伤害提高，**此效果会随着护盾的消失而消失**。”

然而在当前版本实战与客户端底层逻辑排查中发现：
1. 当由 1 技能【胜军之加护】（全队护盾，持续 5 秒，CD 20 秒）或天赋被动【圣女之凝眸】（单体护盾）施加护盾后，如果目标身上的护盾**未被敌方伤害击破、而是达到 5 秒自然超时消失**，其附带的伤害提高效果（`Buff_Hero051Star2Use`）**不会随之移除**；
2. 由于该增伤子 Buff 配置的持续时间为 `buffTime: 0`（无自带倒计时），导致队友在护盾消失后，依然**永久保留全伤害加成**；
3. 即使技能进入长达 15 秒的冷却真空期，甚至脱离战斗切换区域，增伤效果依旧持续存在，造成了增伤效果 100% 全程常驻的异常。

---

## 二、 复现条件与步骤

### 1. 必要前置条件
1. **阿莱克西娅**：星阶达到 2 星及以上，激活 2 星天赋【龙力之祝福】（`hero051Star2`）。

### 2. 触发过程
1. 进入战斗，阿莱克西娅施放 1 技能【胜军之加护】（或被动天赋触发护盾），全队获得水盾及【龙力之祝福】增伤效果（角色状态栏出现 `buff_021` 图标）。
2. 在接下来的 5 秒内，让受盾角色处于安全站位（或未承受足以击破护盾的高额伤害），直至护盾达到 5 秒上限**自然消散**。
3. 护盾特效消失后观察角色：
   - 护盾生命槽正常归零并消失；
   - 角色状态栏中的【龙力之祝福】图标（`buff_021`）依然存在；
   - 角色打出的伤害数值依然享受 +10%~+25% 的增伤幅度；
   - 技能进入 15 秒冷却真空期期间，增伤始终未掉；
   - 甚至通过传送门进入下一层/下一房间后，该增伤依然常驻。

## 三、 代码底层根因分析（技术定位）

经排查客户端代码程序集（`Assembly-CSharp.dll`）与配置表（`buff.json`），该异常是由**「子 Buff 生命周期设计为永久」与「父级护盾结束回调遗漏清理函数」**共同导致的：

### 1. 机制初始化：动态附加无独立计时的子 Buff

在 `Buff_Hero051Star2.cs` 的 `InitBuffPara()` 中，阿莱克西娅 2 星天赋会动态构造新的水盾配置 `newBuffConf`，并在参数字典中注入关联的增伤子 Buff ID：

```csharp
// Buff_Hero051Star2.cs 第 26~32 行
AddNewBuffInfo addNewBuffInfo = new AddNewBuffInfo();
addNewBuffInfo.newBuffTime = buffByBuffID.buffTime;
addNewBuffInfo.newBuffBaseId = addBuffId;
Dictionary<string, object> dictionary = new Dictionary<string, object>();
foreach (KeyValuePair<string, object> item in buffByBuffID.para)
{
    dictionary.Add(item.Key, item.Value);
}
dictionary.Add("addNewBuffId", addNewBuffId); // 注入 051Star2Use1 ~ 051Star2Use4
```

而在 `buff.json` 中，`051Star2Use1` ~ `051Star2Use4` 的配置为：
* `buffTime: 0`（无倒计时，生命周期完全由外部控制）；
* `buffAdd: "unitAtkDamAddValue"`（全伤害提升 10%~25%）；
* `canOverlay: false`（不可叠层，重复施加时刷新）。

当 1 技能释放时，`Buff_hero051Skill1.cs` 的 `StartAction()` 会为目标同时添加护盾与增伤子 Buff：

```csharp
// Buff_hero051Skill1.cs 第 54~62 行
public override void StartAction()
{
    base.StartAction();
    shieldValue = (int)(self.unitData.magicAtk * shieldValueRate);
    currentShieldValue = shieldValue;
    AddShiled(target, shieldValue);
    if (!string.IsNullOrEmpty(addBuffId))
    {
        BuffControl.instance.AddBuff(target, self, addBuffId);
    }
}
```

---

### 2. 关键遗漏点：`EndAction()` 未调用 `ResetTempBuff()`

在 `Buff_hero051Skill1.cs` 中，原本专门编写了用于移除增伤子 Buff 的清理方法 `ResetTempBuff()`：

```csharp
// Buff_hero051Skill1.cs 第 64~72 行
public void ResetTempBuff()
{
    Buff_Hero051Star2Use component = target.buffRoot.GetComponent<Buff_Hero051Star2Use>();
    if ((Object)(object)component != (Object)null)
    {
        Log.V("移除增益buff");
        BuffControl.instance.BuffOver(component);
    }
}
```

对比该类的两个生命周期结束点：

#### （1）护盾被攻击完全打碎时（正常卸载）
```csharp
// Buff_hero051Skill1.cs 第 80~102 行
public void ShiledBreakAction()
{
    if ((Object)(object)target != (Object)null)
    {
        ...
        if (!string.IsNullOrEmpty(addBuffId))
        {
            ResetTempBuff(); // <=== 击破时正确调用了卸载
        }
    }
}
```

#### （2）护盾 5 秒自然超时结束时（遗漏卸载！）
```csharp
// Buff_hero051Skill1.cs 第 74~78 行
public override void EndAction()
{
    base.EndAction();
    RemoveShiled(target, shieldValue);
    // <=== 关键遗漏：此处完全未调用 ResetTempBuff()！
}
```

* **逻辑分析**：
  * 当护盾被怪物高额伤害击破时，走 `ShiledBreakAction()`，增伤 Buff 能被正常移除；
  * 但当护盾 5 秒内未被击破、正常超时消散时，系统引擎调用 `EndAction()`，仅执行了 `RemoveShiled` 移除护盾数值，**漏掉了 `ResetTempBuff()`**；
  * 使得 `Buff_Hero051Star2Use` 成为无宿主绑定的“孤儿 Buff”，并且因为配置 `buffTime: 0` 永不超时，导致增伤属性永久常驻。

---

### 3. 数值叠加机制核实说明

经核对 `BuffControl.instance.AddBuff` 的底层处理：
* `051Star2Use` 在 `buff.json` 中明确声明了 `canOverlay: false`；
* 当阿莱克西娅 20 秒 CD 结束再次释放技能重新套盾时，系统会先通过 `RemoveOldBuff` 将目标身上原有的旧 Buff 销毁（触发其 `EndAction` 减去 25%），再赋予新的 Buff（+25%）；
* 因此，**增伤数值并不会无限翻倍叠加（如 25% → 50% → 75%），而是表现为持续时间无限（从第 1 次套盾起即永久保持增伤常驻）**。

---

### 4. 全包排查与影响范围确认

对客户端全部脚本及所有角色技能配置进行了排查：
1. **全游戏唯一性**：`ResetTempBuff` 方法全游戏**仅存在于 `Buff_hero051Skill1.cs`**。全游戏其他所有具备护盾/增伤联动机制的角色（如夏库塔拉、奥格、埃迪蒂、茜塔、乌帕等），增伤均要么由主 Buff 严格自闭环扣回，要么子 Buff 自带独立的 `buffTime` 倒计时；
2. **唯一受影响角色**：阿莱克西娅是全游戏唯一一个因护盾自然超时而导致增伤永久遗留的角色。

## 四、 供参考的排查与处理方向

可参考以下解决思路：

### 方向一：在护盾自然结束回调中补齐卸载调用
在 `Buff_hero051Skill1.cs` 的 `EndAction()` 中补充子 Buff 的卸载逻辑：

```csharp
public override void EndAction()
{
    base.EndAction();
    RemoveShiled(target, shieldValue);
    // 补齐自然超时销毁逻辑，确保与描述“随护盾消失而消失”一致
    if (!string.IsNullOrEmpty(addBuffId))
    {
        ResetTempBuff();
    }
}
```

### 方向二：为子 Buff 增加独立超时生命周期
在 `Buff_Hero051Star2.cs` 构造 `addNewBuffInfo` 时，或在 `buff.json` 中，为 `051Star2Use` 配置与水盾等长的持续时间（5 秒）：
* 即使在跨房间、意外被打断等极端边缘情况下，子 Buff 也能凭借自身的倒计时自然消除，避免状态无上限残留。
