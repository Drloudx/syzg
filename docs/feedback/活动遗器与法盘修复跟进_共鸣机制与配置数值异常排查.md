## 三、 代码机制 Bug 精确定位

### 1. 「涓流长卷」（`core_102`）Tag 3 触发计数偏移（2 次变 3 次）

* **配置**：`buff.json[relicBuff_Core102_1..5].para` 中 `tag3Para_hitCountAddBuff = 2`。
* **源码定位（`RelicBuff_Core_102.cs` 第 40、123~134 行）**：
  ```csharp
  beHitCount = 0; // 第 40 行初始化
  ...
  else if (curType == "beHit")
  {
      if (beHitCount >= tag3Para_hitCountAddBuff) // ❌ 先判断后自增：0<2→1，1<2→2，第3次 2>=2 才触发
      {
          UIManager.combatPanel.AddBuff(addNewBuff, tar, self);
          beHitCount = 0;
      }
      else
      {
          beHitCount++;
      }
  }
  ```
* **修复建议**：改为先 `beHitCount++;`，再判断 `if (beHitCount >= tag3Para_hitCountAddBuff)` 并清零。

### 2. 「幽夜大弓」（`core_101`）`hit` 标记未重置导致空等冷却

* **源码定位（`RelicBuff_Core_101.cs` 第 58~59、105~136 行）**：
  ```csharp
  hit = false; timer = cdAll; // 第 58~59 行初始化

  private void Update()
  {
      timer += Time.deltaTime;
      if (timer >= cdAll)
      {
          HitAction();
          if (hit)          // ❌ 首次命中后 hit 永久为 true，后续就算 tar == null 未发箭也清零 timer
          {
              timer = 0f;
          }
      }
  }

  public void HitAction()
  {
      ...
      if ((Object)(object)tar != (Object)null)
      {
          EffectControl.instance.CreateBulletEffect(...);
          hit = true;       // ❌ 全局再无置 false 的代码
      }
  }
  ```
* **修复建议**：每次执行 `HitAction()` 前先重置 `hit = false;`（或在 `timer = 0f;` 后立即置 `hit = false;`）。

*(注：其余基础遗器与核心 `core_103`~`core_109` 配置及逻辑经核验均正常。)*
