# Bug 排查：「山神之殒」魔物蛋巢刷入无法进入的隐藏房间（`c2_area4_4`）

> **最新核对版本**：**1.7.15**（`cdnVer: 38`，热更包 `codeVersion: A0A4112C5087F29074EA0C41AD03EE6F`）  
> **核对日期**：2026-11-24  
> **类型**：关卡解锁与采集点随机池配置异常  
> **状态**：**未修复**（2026-11-24 `cdnVer 38` 最新 `room.json` 仅调整了 `stage_c2_area4_1` / `stage_c2_area4_4` 场景装饰物 `decorates`，未调整蛋巢 `spObj` 区间与房间解锁配置）

---

## 一、 现象

在第二章地区 **「山神之殒」**（`area.json[c2_area4]`，玩家常称「山神之陨」）内，野生 **「魔物蛋巢」**（`c2yeWaiPet03` / `yeWaiPet_c2`）按规则在两个子区域中每日随机刷新其一。

但由于其中一个候选点所在房间 **「山神之殒外围」（`c2_area4_4`）在当前版本没有任何解锁途径、玩家无法前往**，只要当天的随机种子落入该房间对应的 `[0.5, 1)` 区间，可进入的 **「安娜的勘测地」（`c2_area4_3`）** 内的蛋巢会被强制隐藏，导致玩家当天在山神之殒摸不到任何魔物蛋巢。

---

## 二、 配置核对

### 1. 候选刷新点分布（`room.json`）

`c2yeWaiPet03` 在 `room.json` 中仅配置于以下两个房间，各自占据 `0.5` 的随机区间：

| 房间 ID | 场景 ID | 房间名 | `spObj` 对象 UID | `caijiTypeId` | 随机区间 `[caijiSeedMin, caijiSeedMax)` | `showCondition` | 玩家可达性 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `c2_area4_3` | `stage_c2_area4_3` | **安娜的勘测地** | `obj1105` | `c2yeWaiPet03` | **`[0, 0.5)`** | `""` | **可达**（由支线 `s_2_2` 解锁） |
| `c2_area4_4` | `stage_c2_area4_4` | **山神之殒外围** | `obj2197` | `c2yeWaiPet03` | **`[0.5, 1)`** | `""` | **不可达**（全库无解锁入口） |

> 另查 `roomCollect.json`：`c2yeWaiPet03 = { "typeId": "c2yeWaiPet03", "name": "魔物蛋巢", "collectTypeId": "yeWaiPet_c2" }`；`roomCollectType.json` 中 `yeWaiPet_c2` 的掉落表为 `reward: "yeWaiPet_c2"`（`crossDay: 1`，每日按地区和采集 ID 重新计算）。

### 2. 「山神之殒外围」（`c2_area4_4`）房间状态（`levelRoom.json` / `task.json`）

`levelRoom.json` 中 `c2_area4` 区域下四个子房间的连通与解锁配置如下：

| 房间 ID | 房间名 | `hiddenRoom` | `baseRoom` | 上级连通门 | 全库解锁来源 |
| --- | --- | --- | --- | --- | --- |
| `c2_area4_1` | 山神之殒 | `false` | `false` | 地区入口 `portal`；含门 `doorLD → c2_area4_2`、`doorLU → c2_area4_4` | 地区主入口 |
| `c2_area4_2` | 安娜的试验场 | `true` | `false` | `c2_area4_1` 的 `doorLD` | 支线 `s_2_2` 第 5 步 `stepUnlockStage: ["c2_area4_2"]` |
| `c2_area4_3` | 安娜的勘测地 | `true` | `false` | `c2_area4_2` 的 `doorRU` | 支线 `s_2_2` 第 6 步 `stepUnlockStage: ["c2_area4_3"]` |
| **`c2_area4_4`** | **山神之殒外围** | **`true`** | **`false`** | `c2_area4_1` 的 `doorLU` | **无**（`unlockStage: []`；全部配置表与剧情脚本均无任何引用） |

### 1. 未解锁隐藏房间入口直接被隐藏

```csharp
// RoomCreateController.cs 第 4213~4217、4327~4330 行

if (roomLevelDataById.hiddenRoom && !GameDataManager.serverData.recordData.CheckUnLockStage(roomLevelDataById.typeId))
```

即使绕过隐藏尝试交互，也会在同文件第 `4291~4293` 行被拦截：


### 2. 随机种子命中 `[0.5, 1)` 时隐藏勘测地蛋巢

```csharp
// ExtentionMethod.cs 第 2742~2749 行
public static string GetCollectSeedValue(string areaNo, string collectNo)
{
    if (areaNo == "")
    {
        return GetCurrentDay() + collectNo + 2;
    }
    return GetCurrentDay() + areaNo + collectNo + 2;
}

// RoomCreateController.cs 第 3109~3118 行
float xRandomValue = ExtentionMethod.GetXRandomValue(ExtentionMethod.GetCollectSeedValue(areaNo, data.typeId));
if (xRandomValue < interObjData.caijiSeedMin || xRandomValue >= interObjData.caijiSeedMax)
{
    objGo.SetActive(false); // ❌ 当 xRandomValue ∈ [0.5, 1) 时，c2_area4_3 的 obj1105 隐藏，仅刷在进不去的 c2_area4_4
    ...
}
```

`c2_area4` 下所有房间共用同一个 `areaNo`（`"18"`）与同一个采集表 ID（`"c2yeWaiPet03"`），每日计算出的 `xRandomValue` 完全一致。一旦该值落在 `[0.5, 1)`，玩家既无法在 `c2_area4_3` 看到蛋巢，又无法前往 `c2_area4_4`，形成当天整张图蛋巢空刷。

## 四、 全图同类型魔物蛋巢横向普查

全量排查 `room.json` 中全部 13 组共 26 个 `yeWaiPet` 魔物蛋巢刷新点（`c1yeWaiPet01~04`、`c2yeWaiPet01~03`、`c3yeWaiPet01~03`、`c4yeWaiPet01~03`）：

- **全图仅「山神之殒外围」（`c2_area4_4`）一处存在“配置了 `yeWaiPet` 刷新但房间全库无解锁途径”的死区问题。**

## 五、 修复建议（二选一）

1. **只改刷新点配置（最稳妥、不改关卡流程）**：
   - 将 `room.json[stage_c2_area4_3]` 中 `obj1105` 的区间改为 `caijiSeedMin: 0`、`caijiSeedMax: 1`；
   - 移除 `room.json[stage_c2_area4_4]` 的 `obj2197`，或将其转移到同图已可进入的 `stage_c2_area4_2`（安娜的试验场）并维持 50%/50% 对分。
2. **若「山神之殒外围」本意为可前往区域**：
   - 将 `levelRoom.json[c2_area4_4].hiddenRoom` 改为 `false`，或在对应任务/前置房间 `unlockStage` 中补上 `"c2_area4_4"`（注意 `c2_area4_4` 当前 `gameLevel: 1` 且 `room.json[stage_c2_area4_4]` 仍有一处隐藏收集点 `c2yinCang03`，若开放房间需一并确认 `gameLevel` 与场景内怪物/事件配置是否已完工）。
