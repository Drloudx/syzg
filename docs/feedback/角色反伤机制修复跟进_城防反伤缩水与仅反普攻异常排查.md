## 三、 精确配置与源码定位

### 1. 基础栅栏（`s1_wall_1`）Lv.2~3 反伤配置仍小 100 倍（`defense.json`）

* **代码消费口径**：`BattleManager.cs` 第 13559 行原样赋值 `unit.unitData.rebDam = unitConf.levelAttrConf.rebDam;`，结算时 `CombatPanel.cs` 第 6739 行固定除以 `100f`：
  ```csharp
  int baseDamage = (int)((float)finalDamage * target.unitData.rebDam / 100f);
  ```
* **`defense.json` 现状**：
  - `s1_wall_1` Lv.1 `rebDam` 已改为 **`30`**（实机 `30%`）；
  - `s1_wall_1` **Lv.2 与 Lv.3** 的 `rebDam` 仍残留 **`0.3`** → 升级栅栏后实机反而变成 `0.3 / 100f = 0.3%`。
* **修复建议**：将 `defense.json[buildInfo.s1_wall_1.level]` 中 `"2"` 与 `"3"` 级的 `rebDam` 同步改为 `30`。

### 2. 全局反伤仅反普通攻击，且按魔法伤害吃敌方双抗

```csharp
// CombatPanel.cs 第 6737~6750 行

{                                          // ❌ 仅拦截 normalAtk；技能/持续伤害完全不触发
    int baseDamage = (int)((float)finalDamage * target.unitData.rebDam / 100f); // ❌ 基数为减伤/护盾后的 finalDamage
    DamageInfo damageInfo2 = new DamageInfo();

    damageInfo2.damageFromSkill = "";
    damageInfo2.damageType = "magicAtk";   // ❌ 走魔法伤害减伤流程，被攻击者魔防/魔抗二次削减
    damageInfo2.muPower = 0f;
    damageInfo2.muAddType = "magicAtk";
    ...
    damageInfo2.formType = DamageFormType.buff;
```

* **影响示例**：迈妮娅（`hero_046`）2 技能反击假人（`04603`）文案写“任何攻击稻草人的敌人都会遭到反击，造成等同于该次攻击 `100%` 的伤害”，实际敌人放技能打假人 `0` 反伤，普攻反弹也会被敌方魔防/魔抗减免。
* **修复建议**：若机制按普攻设计则同步更新技能文案；若确需反击所有伤害，需放开 `formType` 限制并明确是否走真伤（`realDam: true`）。
