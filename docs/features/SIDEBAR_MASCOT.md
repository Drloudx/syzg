# 右栏吉祥物

本专题集中维护右栏插画、动作和模型约定；公共按钮、选择浮窗及主题规则仍由 [UI 组件库](../UI_COMPONENT_LIBRARY.md) 定义。

## 展示与加载

`SidebarMascot.vue` 在非原生、宽度 ≥1025px 且高度 ≥700px 的普通 Wiki 页面按需加载；招募独立布局不挂载。插画放在右栏说明之后，使用正常布局流靠右下，不遮挡正文、不截获点击。

配置覆盖 34 名角色，默认 001 希尔；素材在 `src/assets/mascot/`。角色配置与资产入口由 `config/mascots.js` 管理，`utils/mascotArtwork.js` 加载并校验可信本地 SVG、缓存成功结果。主插画仅加载当前角色，选择窗仅加载当前批次，切换或卸载取消过期请求；失败保留原角色并可重试。

## 尺寸与交互

- 主插画和静态预览共用 320×400 画布；桌面宽 192px，700～780px 高窗口宽 144px。身体落脚中心为 (162,369)，不按武器、篮子或尾羽的外接框居中。
- `MASCOTS.standingHeight` / `getMascotScale` 将待机第 0 帧可见身高（不含阴影）统一到 312 模型单位。每人使用固定等比例缩放，动作切换不重新按包围盒缩放；人物和道具共同缩放，保留握点与鱼线连接。
- 提供待机、思考、秋千、钓鱼及完整进出场。暂停、动作和角色选择分别持久化；后台或不可见时暂停，减少动态效果时关闭关键帧并保留静态角色选择。选择预览禁用动画。
- 操作使用公共 `UiButton`，动作和角色选择使用 `UiPopover`。角色每批七人，共五批、末批六人；翻批只换候选，点选才切角色。重新打开定位当前角色所在批次，成功选择后关闭并恢复焦点。
- 选择浮窗向上展开、收敛在视口内，使用 `paper-panel corner-nails`；点窗外、Esc、路由变化关闭，不锁背景。问号固定右上，尾部朝向左下的人物。

## 模型与动作

`MascotScene` / `MascotFigure` 装配场景和人物，`MascotArm` / `MascotLeg` 复用关节绘制，`mascotModels.js` 及 `mascotRedrawnModels.js`、`mascotRedrawnBatch3/4/5.js` 管理专属模型配置。`useMascotChoreography` 协调进出场与连续选择，只在当前进出场完成后响应最后一次动作请求。

SVG 按 `hero-<三位编号>-idle.svg` 命名，保存语义分件，完整姿势由组件装配；不把裸分件 SVG 当成最终预览。保持参考人物的头饰、发型、武器、左右服饰差异和原比例，使用细描边、平涂及分区阴影，不通过换色或整图旋转冒充关节动作。

- `upperArm/cuff/thigh/shin/boot` 可提供左右独立分件；肩袖随上臂、袖口随手腕、腿饰随对应腿段。`satchelLayer` 控制身体后、腰前或手臂前的佩饰层级，每次只渲染一份。
- 以掌心求解握点，将掌心偏移计入可达距离，手腕顺着前臂；思考调整肩肘腕与另一只自然垂落的手臂。握绳、握竿时肘部低于肩点，检查掌心接触和腕部折角。
- 思考依次抬臂、斜托下巴、偏头；退出先收手再回正。允许专门配置袖管折叠投影，但总臂长与手掌缩放不变，袖管与关节同步过渡。
- 秋千包括道具出现、靠近、握绳、坐下、轻荡；退出依次减速、松手、跳下、落地、走开、收起。钓鱼包括道具出现、侧坐、拿竿、放线、看漂与提竿；退出依次收线、放竿、松手起身、走开、收道具。
- 道具停放位置与取放轨迹连续，右手握竿柄前段、左手靠近卷线轮，双肘下沉；鱼漂与鱼线始终相连，保留水潭与靴子、凳子之间的岸边。

## 角色适配与检查

希尔保留手套与服装；迦南保留裸手、褶边袖口、护腿、长靴、佩剑及披风，坐姿时佩剑贴背、披风收拢，起身恢复。米托拉保留头部 0.9 比例、红白长发、披肩、吊坠、绑带袖口、左露指手套和不对称袜靴；长发与坐姿同步收拢，鱼竿取放时右肘保持在肩点外下方。

露比特的菜篮与园艺手套、艾薇杜尔的灯杖与长袍、露帕的法杖与披风、菲莉娜的尾羽、箭筒与爪靴分别适配；长装饰随坐姿收拢，宽武器和翅膀完整展示，不横向挤压人物。露帕的托腮袖管可独立配置投影比例。

离线绘制源为 `scripts/dev/mascot-drawings*.mjs` 与 `mascot-drawing-details.mjs`，`review-mascots.mjs` 生成原图与四动作对照。检查完整装配后的轮廓、握点、遮挡、边界和 SVG 错误；配件仅存在于源码中不能算实际可见。逐次修复记录留在开发日志，整理前细节见 [历史摘录](../../backups/audits-archive/DOC_DETAILS_2026-09-16.md)。
