## 三、本次踩到的四个坑（已修，但会重复出现）

### 1. `flex: 1 0 auto` 不能拆成 `flex-grow: 1`

`App.vue` 桌面端有 `.app-main :deep([data-main-scroll]) { flex: none }`，带属性选择器且处于 scoped，特异性高于普通类选择器。

- 只写 `flex-grow: 1` → **被整条 `flex` 简写覆盖，计算值仍是 0**（已实测确认）
- 必须写 `flex: 1 0 auto` 简写

同类先例：`.camp-panel > .camp-grid { flex: 1 0 auto }`。

### 2. column flex 里的卡片要写 `flex-shrink: 0`

`.admin-workshop` 是 `display:flex; flex-direction:column`，子项默认 `flex-shrink:1`。内容超出时被按比例压扁，配 `overflow:hidden` 就表现为「后面的元素消失」。

实测：公告插槽 4 行内容高 258px → 被压到 179px，第 3、4 行被裁掉。

### 3. 用 `!important` 覆盖组件样式时，必须把被覆盖的属性也写全

`.equips-content` 与组件自带的 `.ui-card-grid-scroll` 是同一元素。写了 `flex`/`display` 的 `!important` 后，若漏写 `overflow-y`，计算值回落到 `visible` —— **滚动能力被静默干掉**。

### 4. 不要用 `git show > file` 恢复 UTF-8 文件

PowerShell 重定向会破坏编码，git 会把它识别为二进制差异。用 Node：

```js
execSync("git show HEAD:path", { encoding: "buffer" })
writeFileSync("path", buf)
```

### 5. 写文档会打挂 Vite dev server（已修）

编辑工具写文件是「先写 `.xxx.tmp` → 改名」的原子替换，会在目录里短暂产生
`.{文件名}.{pid}.{uuid}.tmpdir/{文件名}.tmp`。Vite 默认监听整个项目根，
扫到该临时文件时被 Windows 锁住：

```
Error: EBUSY: resource busy or locked, watch '...tmp'
```

**这是未捕获异常，直接杀掉 dev server 进程。**

已在 `vite.config.js` 加 `server.watch.ignored`，忽略 `docs` / `backups` / `raw` /
`游戏数据` / `scratch` / `tools` 与 `*.tmp`。实测改文档后前端存活。
