# 2026-09-07 开发汇总

## UI 与交互

- Android 页面历史交还 Capacitor 原生默认处理。移除常驻 `backButton` 监听、按 `/recipes` 路径强退和自定义 `router.back()`；仅存在弹窗、菜单、有效搜索下拉时临时注册，关闭最上层界面后释放。下载中的更新弹窗会消费返回而不关闭。当前安装的原生插件在没有 WebView 历史时不主动退出，不新增主页退出策略。
- `UiModal` 接入 `overlayStack`、`useOverlay`、引用计数 `globalModalLock`；保留内嵌详情既有滚动协调器。全局弹窗锁定背景、约束正文高度、保留底部操作区，并处理安全区、Escape 和焦点循环。更新提示、隐藏点位大图复用 `UiModal`。
- 物品与任务使用 `@tanstack/vue-virtual` 的按行虚拟网格，复用原响应式列数与卡片；保留深层详情返回位置、嵌套返回和分享链接定位。移动末尾留白避免固定按钮遮住最后一项。
- 副本封面接近可视区域才赋图片地址，保留 `loading="lazy"`、异步解码与固定布局。原生 lazy 在 Chrome 中仍会预读全部短列表，补充 IntersectionObserver 控制实际请求；副本末尾同步保留悬浮控件空间。
- 全站统一 `--font-ui`，只保留 HarmonyOS，缺字交给系统字体；移除两份 MYR2Sans，共 19,835,296 字节。深木标题/按钮及封面文字使用独立前景 Token，修正暗色低对比。
- 修复原生宽屏仍占三栏中第一列的问题，顶栏名称与现有导航保持一致，横屏左右边距纳入安全区。

## 数据与解析

- `raw/mon.json` 保持原表；核对构建期 `cirtDam -> critDam` 等归一化仍在 `scripts/parse/shared.mjs`，本批不手工改写原表。
- JSON 请求共享待完成/成功缓存，失败不缓存为空数据；超时、格式错误和关键结构缺失可以显式重试。物品、装备、怪物详情及共享来源资源增加错误状态和过期请求保护。
- Vite 为 parsed 主表、副本详情、角色剧情、任务剧情分别生成带内容指纹的清单。清单按目录首次使用时读取，校验 JSON 的 SHA-256；新 CDN 数据不能混入旧代码包，校验失败回退包内同路径、同版本数据。公告保留实时请求。
- 图片统一有限降级：CDN、包内同路径、现有中性占位；特殊怪物图保留命名候选且每项最多尝试一次，避免旧回调循环或提前隐藏图片。
- 封面图片已压缩：本次核对的 10 张现有封面合计 6,405,909 字节，对应备份原图 12,841,834 字节，减少 50.12%。没有重新压缩或替换任何图片原件。

## Bug 修复

- 热更版本以 `CapacitorUpdater.current()` 的实际活动包为准，兼容记录只描述当前包；不再在下载/激活之前保存目标版本，回滚后仍能再次检查更新。
- 原生下载监听先等待注册，在成功、异常、销毁路径释放；热更监听在激活重载前清理。APK 下载失败可重试，更新说明过长时底部按钮仍可见。
- 原生返回监听的异步注册/移除串行化；移除失败保留句柄供后续清理重试，避免丢失句柄后重复监听。
- 搜索与设置避免同时叠开，纯空格查询不注册不存在的搜索覆盖层。
